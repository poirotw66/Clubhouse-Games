# 接龍（Klondike Solitaire）

## 類別

紙牌類型

## 概述

接龍（Klondike，俗稱 Solitaire 或 Patience）是最常見的單人接龍。七列牌疊以紅黑交替、點數遞減接龍，四疊 foundation 從 A 依同花色遞增到 K。牌堆可翻牌到廢牌堆再接到牌疊或 foundation，目標是將全部 52 張牌移上 foundation。

本館數位版另提供 **標準／維加斯計分**、**保證可解發牌**、**每日一局（台北時間）**、**挑戰目標** 與完整戰績，讓翻牌與循環牌堆成為有代價的取捨。

## 人數與建議年齡

- 人數：1 人。
- 建議年齡：約 8 歲以上。

## 所需器材

- 標準 52 張撲克牌（無鬼牌）。

## 遊戲目標

在 **四疊 foundation** 上，依 **花色** 從 A 到 K 各完成一疊，即獲勝。牌需經由 **七列牌疊（tableau）** 與 **牌堆／廢牌堆** 中轉。

## 規則說明

### 準備／設定

1. **Tableau**：發成七列。第 1 列 1 張、第 2 列 2 張…第 7 列 7 張；每列只有 **最上面一張** 翻開，其餘蓋牌。
2. **牌堆（Stock）**：剩餘 24 張牌面朝上疊放，供翻牌。
3. **廢牌堆（Waste）**：從牌堆翻出的牌暫放於此，只有最上面一張可打。
4. **Foundation**：四個空位，起始為空。

### 回合流程與移動規則

1. **Foundation**：從 A 開始，同花色依序 A→2→…→K。只有符合「下一張」的牌可移上去；A 可從 tableau 或 waste 直接移入。
2. **Tableau 接牌**：可把單張或「紅黑交替、點數遞減」的一串牌移到另一列頂張之下。例如黑 6 可接在紅 7 下；可一次移動整串（如 黑6-紅5-黑4）。
3. **空列**：只有 **K** 或「以 K 為首的一串」可放入空列。
4. **翻牌**：從牌堆翻 1 張（或 3 張，依設定）到廢牌堆頂；廢牌堆頂張可打到 tableau 或 foundation。牌堆翻完後可依規則將廢牌堆重新翻回牌堆（見計分／維加斯限制）。
5. **翻開蓋牌**：某列全部翻開的牌移走後，可翻開該列最上面的蓋牌。

### 可行動作與限制

- 只有 tableau 每列的 **頂張**、廢牌堆 **頂張** 可移動。
- Tableau 必須 **紅黑交替、點數遞減**；Foundation 必須 **同花色遞增**。
- 翻牌次數（一次 1 張或 3 張）可切換，影響難度與循環代價。

### 特殊狀況

- **無合法移動**：若無法再移動且未完成四疊 foundation，則失敗。
- 可從 foundation 移回 tableau（標準計分會扣分）。

## 勝負條件

- 當四疊 foundation 皆為同花色 A～K 時，**獲勝**。
- 若牌堆與廢牌堆已無法再翻且無合法移動，則 **失敗**。

## 數位版模式與計分

### 翻 1／翻 3

牌堆每次翻 1 張較易，翻 3 張較難。

### 標準計分（Windows Solitaire 風格）

| 事件 | 分數 |
|------|------|
| 牌移上 foundation | +10 |
| 翻開 tableau 蓋牌 | +5 |
| 廢牌接到 tableau | +5 |
| 自 foundation 移回 | −15 |
| 每次悔棋（額外） | −2 |
| 循環牌堆（翻 1） | −100 |
| 循環牌堆（翻 3） | −20 |
| 每滿 10 秒 | −2 |
| 通關（≥30 秒） | ⌊700000／秒數⌋ 加分 |

### 維加斯計分（累計籌碼）

- 每局開局 **−52**；每張上 foundation **+5**。
- 局末分數累加至 **維加斯籌碼**（跨局保留）。
- **翻 1**：不可循環牌堆（只能過一輪）。
- **翻 3**：最多循環兩次（共三輪過牌）。

### 保證可解發牌

開啟「可解局」後，以 thoughtful Klondike solver 篩選種子；若時限內找不到，則改用反向／腳本構局，保證存在完美資訊解。

### 每日一局

- 以 **亞洲／台北時間（UTC+8）** 的日期字串產生種子，全服同日同局（保證可解）。
- 通關記入每日紀錄（保留 **今日最佳**）並計算 **連續天數**（允許到昨天為止仍連續）。
- 提供可複製的分享文字（日期、勝負、分數／時間／步數、翻牌與計分模式、連勝天數）。

### 挑戰目標

通關時自動結算，例如：

- 無悔棋通關
- ≤120／≤80 步
- ≤5 分鐘
- 標準分 ≥300
- 維加斯單局 >0（淨賺）

### 戰績

本地記錄：場次、勝場、勝率、目前／最長連勝、各模式（翻牌×計分）最佳分數／時間／步數、維加斯籌碼、挑戰完成次數、每日連續。

### 雙翼皇家戰術指揮艙（Dual-wing Royal Table Cockpit）

為徹底提升單人接龍沉浸感與策略決策效率，本館數位版創新打造雙翼皇家戰術指揮艙，將牌桌拓展為全方位戰術指揮台：

- **左翼：戰術情報雷達（Tactical Telemetry Radar）**：
  - **牌庫循環與 X-Ray 深度透視**：即時掌握未翻牌庫與廢牌堆張數，維加斯模式專屬剩餘輪次嚴格倒數（翻 1 限 1 輪、翻 3 限 3 輪），標準計分次回循環扣分預警。內建 **牌庫色系透視（紅黑卡牌分佈條）** 與 **基座關鍵牌雷達**，即時偵測四門花色當前急需牌（如 ♠3、♥A）是否正潛伏於牌庫待掘。
  - **暗牌深層分佈熱圖**：以 7 列立體等化器直觀呈現每列蓋牌深度，標靶高亮最深暗牌突破口，即時計算已翻開比例（X / 21 張，%）與「全解就緒」光環。
  - **四色回收天秤與推進速度儀（Foundation Velocity Meter）**：♠ 黑桃、♥ 紅心、♣ 梅花、♦ 方塊 0～13 收牌天秤，自動辨識花色落後幅度；搭配動態推進儀（張/分）與三段衝刺狀態（蓄力中、穩定推進、極速連收）。
  - **戰術視野開關**：一鍵開啟「高亮所有可動牌」，桌面所有具備合法路徑之牌面即時以琥珀金色光環標示；隨附「一鍵自動收牌」捷徑。

- **右翼：破局大師與維加斯收益儀（Master Mindset & Vegas Yield）**：
  - **解局步數效率儀（Step Efficiency Gauge）**：依據基準步數（~80 步）與推進進度，實時評定「S級 傳奇指揮」、「A級 精準調度」、「B級 穩健前行」、「C級 迂迴摸索」，激勵玩家追求最高步數效率。
  - **維加斯賭局收益儀**：實時計算開局底注（-$52）、每張收牌回饋（+$5）、本局淨盈虧（即時綠/金/赤色標示）、回本線倒數計（還需 N 張牌回本），並啟動連勝光環狂熱加成（Streak Fever Aura：連勝起勢 x1.2、連勝狂熱 x1.5、維加斯傳奇 x2.0）。
  - **標準積分與時限折損儀**：每滿 10 秒 −2 分倒數提醒，同步預估通關時間獎勵（⌊700,000 / 秒數⌋）。
  - **破局大師動態錦囊**：依即時盤面生成動態提示（如空列預留國王 K、第 N 列深層暗牌突破、花色失衡警訊、牌庫巡檢提醒）。
  - **鍵盤指揮官快捷鍵系統（Keyboard Commander HUD）**：
    - <kbd>Space</kbd>：翻牌 / 循環牌庫
    - <kbd>1</kbd>～<kbd>7</kbd>：選取或移動至對應牌列
    - <kbd>0</kbd> 或 <kbd>W</kbd>：選取廢牌堆頂張
    - <kbd>A</kbd>：一鍵自動收牌
    - <kbd>H</kbd>：破局提示
    - <kbd>Z</kbd>：悔棋復原
    - <kbd>V</kbd>：戰術視野切換
    - <kbd>N</kbd>：快速新局

- **行動端戰術速報條（Mobile Tactical Strip）**：
  - 於手機與平板直屏環境下，雙翼自動轉化為頂部半透明微光戰術條，精簡呈顯暗牌數、牌庫數、收牌推進速度、維加斯淨利或步數效率，並提供即時收牌與提示按鈕，點擊「儀表」即可隨時展開完整雙翼戰術抽屜。

### 3D 卡牌物理、原生 Web Audio 音效與經典彈跳瀑布慶典

- **3D 立體卡牌與燙金邊框（Gilded Edge）**：
  - 牌面具備精緻燙金光澤鑲邊（Gilded Edge）與立體層次，懸停與拖曳時觸發 3D 動態陰影與微距抬升（elevated lift）。
  - 牌桌採用皇家墨綠聚光呢毯（VIP Table Illumination），中央牌區柔和聚光光環與金絲邊界。
- **原生 Web Audio 音效引擎（klondikeAudio）**：
  - 紙牌滑動翻面風切聲（Card Flick）、落桌清脆敲擊聲（Card Snap）、發牌機關洗牌聲（Riffle Shuffle）。
  - 階梯爬音和弦（Ascending Cascade Arpeggio）：每張牌進駐基座時依進度動態演奏大調五聲音階水晶爬音，連續收牌時展現極具成就感的和弦琴音。
- **維加斯經典彈跳瀑布慶典（WinCascade）**：
  - 通關時觸發 52 張卡牌物理重力彈跳（經典 Windows 接龍彈跳軌跡畫布），伴隨低頻震撼重低音（Bass Drop）、煙火粒子盛典，點擊畫面任意處更可直接施放慶祝煙火！

### 其他

## 櫻井政博遊戲手感與體驗設計

本遊戲深度融合櫻井政博遊戲設計哲學：

- **fx-004 物理撞擊與微震動反饋（Physical Impact & Shake）**：
  - 翻牌、循環摸牌與卡牌落列時觸發輕快物理微震動（`shake 0.1~0.22`）與觸覺反饋（`haptic tap`），強化紙牌觸底沉浸手感。
  - 移入回收區（Foundation）給予成功肯定震動（`shake 0.22`，`haptic success`）。
  - 通關時連動 Windows 經典卡牌重力彈跳瀑布（`WinCascade`）、全螢幕震動（`shake 0.8`）與彩帶粒子（`particles confetti`）。
  - 無步可走陷入死局時觸發柔和警示震動（`shake 0.35`，`haptic error`）。
- **fx-005 節奏連擊與音階攀升（Rhythm & Pitch Ascent）**：
  - 每張牌進駐回收區時，五聲音階水晶琶音隨已收牌張數動態調升音高（`playFoundationAscent`），自動全解收牌時形成極具成就感的連鎖和弦音樂回饋。
- **gameplay-core-001 風險與回報清晰化（Risk vs Reward）**：
  - 維加斯模式即時顯示底注 -$52 與回本線倒數計，精準掌握下注風險曲線。
  - 解局步數效率儀（Step Efficiency Gauge）即時評等 S/A/B/C 級，激勵深層暗牌探勘與步數最佳化。
- **gameplay-ux-009 快速重試與操作流暢度（Rapid Retry & Zero Friction）**：
  - 結算畫面（過關或無步可走）全局監聽 <kbd>Space</kbd>、<kbd>Enter</kbd>、<kbd>R</kbd> 快捷鍵，瞬間開啟新局或重新洗牌，無須點擊滑鼠。
  - 結算按鈕清楚提示 `(Space / Enter / R)`。
  - 規則對話框內嵌 Juice 手感回饋控制面板，支援自訂震動與粒子強度。

## 常見變體或可選規則

- **翻牌次數**：限一輪、三輪或無限輪（維加斯已內建限制）。
- **Thoughtful Klondike**：已知全部牌面（solver 以此模型篩選可解局）。
- **雙人接龍**：兩人各一副牌，共用四疊 foundation，先出完者勝（本館未實作）。
