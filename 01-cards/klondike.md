# 接龍（Klondike Solitaire）

## 類別

紙牌類型

## 概述

接龍（Klondike，俗稱 Solitaire 或 Patience）是最常見的單人接龍。七列牌疊以紅黑交替、點數遞減接龍，四疊 foundation 從 A 依同花色遞增到 K。牌堆可翻牌到廢牌堆再接到牌疊或 foundation，目標是將全部 52 張牌移上 foundation。

本館數位版另提供 **標準／維加斯計分**、**保證可解發牌**、**每日一局（台北時間）**、**挑戰目標** 與完整戰績，讓翻牌與循環牌堆成為有代價的取捨。

## 人數與建議年齡

- 人數：1 人。
- 建議年齡：約 8 歲以上。

## 所需器材

- 標準 52 張撲克牌（無鬼牌）。

## 遊戲目標

在 **四疊 foundation** 上，依 **花色** 從 A 到 K 各完成一疊，即獲勝。牌需經由 **七列牌疊（tableau）** 與 **牌堆／廢牌堆** 中轉。

## 規則說明

### 準備／設定

1. **Tableau**：發成七列。第 1 列 1 張、第 2 列 2 張…第 7 列 7 張；每列只有 **最上面一張** 翻開，其餘蓋牌。
2. **牌堆（Stock）**：剩餘 24 張牌面朝上疊放，供翻牌。
3. **廢牌堆（Waste）**：從牌堆翻出的牌暫放於此，只有最上面一張可打。
4. **Foundation**：四個空位，起始為空。

### 回合流程與移動規則

1. **Foundation**：從 A 開始，同花色依序 A→2→…→K。只有符合「下一張」的牌可移上去；A 可從 tableau 或 waste 直接移入。
2. **Tableau 接牌**：可把單張或「紅黑交替、點數遞減」的一串牌移到另一列頂張之下。例如黑 6 可接在紅 7 下；可一次移動整串（如 黑6-紅5-黑4）。
3. **空列**：只有 **K** 或「以 K 為首的一串」可放入空列。
4. **翻牌**：從牌堆翻 1 張（或 3 張，依設定）到廢牌堆頂；廢牌堆頂張可打到 tableau 或 foundation。牌堆翻完後可依規則將廢牌堆重新翻回牌堆（見計分／維加斯限制）。
5. **翻開蓋牌**：某列全部翻開的牌移走後，可翻開該列最上面的蓋牌。

### 可行動作與限制

- 只有 tableau 每列的 **頂張**、廢牌堆 **頂張** 可移動。
- Tableau 必須 **紅黑交替、點數遞減**；Foundation 必須 **同花色遞增**。
- 翻牌次數（一次 1 張或 3 張）可切換，影響難度與循環代價。

### 特殊狀況

- **無合法移動**：若無法再移動且未完成四疊 foundation，則失敗。
- 可從 foundation 移回 tableau（標準計分會扣分）。

## 勝負條件

- 當四疊 foundation 皆為同花色 A～K 時，**獲勝**。
- 若牌堆與廢牌堆已無法再翻且無合法移動，則 **失敗**。

## 數位版模式與計分

### 翻 1／翻 3

牌堆每次翻 1 張較易，翻 3 張較難。

### 標準計分（Windows Solitaire 風格）

| 事件 | 分數 |
|------|------|
| 牌移上 foundation | +10 |
| 翻開 tableau 蓋牌 | +5 |
| 廢牌接到 tableau | +5 |
| 自 foundation 移回 | −15 |
| 每次悔棋（額外） | −2 |
| 循環牌堆（翻 1） | −100 |
| 循環牌堆（翻 3） | −20 |
| 每滿 10 秒 | −2 |
| 通關（≥30 秒） | ⌊700000／秒數⌋ 加分 |

### 維加斯計分（累計籌碼）

- 每局開局 **−52**；每張上 foundation **+5**。
- 局末分數累加至 **維加斯籌碼**（跨局保留）。
- **翻 1**：不可循環牌堆（只能過一輪）。
- **翻 3**：最多循環兩次（共三輪過牌）。

### 保證可解發牌

開啟「可解局」後，以 thoughtful Klondike solver 篩選種子；若時限內找不到，則改用反向／腳本構局，保證存在完美資訊解。

### 每日一局

- 以 **亞洲／台北時間（UTC+8）** 的日期字串產生種子，全服同日同局（保證可解）。
- 通關記入每日紀錄（保留 **今日最佳**）並計算 **連續天數**（允許到昨天為止仍連續）。
- 提供可複製的分享文字（日期、勝負、分數／時間／步數、翻牌與計分模式、連勝天數）。

### 挑戰目標

通關時自動結算，例如：

- 無悔棋通關
- ≤120／≤80 步
- ≤5 分鐘
- 標準分 ≥300
- 維加斯單局 >0（淨賺）

### 戰績

本地記錄：場次、勝場、勝率、目前／最長連勝、各模式（翻牌×計分）最佳分數／時間／步數、維加斯籌碼、挑戰完成次數、每日連續。

### 其他

- **提示**、**自動完成**、**悔棋**、局號發牌／同局重發。
- 收牌飛牌動畫、勝利瀑布、共用 `synthAudio` 音效。

## 常見變體或可選規則

- **翻牌次數**：限一輪、三輪或無限輪（維加斯已內建限制）。
- **Thoughtful Klondike**：已知全部牌面（solver 以此模型篩選可解局）。
- **雙人接龍**：兩人各一副牌，共用四疊 foundation，先出完者勝（本館未實作）。
