## 棒球人生（Baseball Life）

文字選項 ＋ 骰子 ＋ 能力養成的 **單人棒球生涯模擬**：16 歲入部，走過高中三年、四場全國賽、一次選秀，再經歷職業、旅外、國際賽、傷病與衰退，最後在引退時接受名人堂票選。

本專案是 `Clubhouse-Games` 底下 `Games/Baseball-Life` 子專案，使用 React + TypeScript + Vite + Tailwind CSS 實作，遊戲邏輯為純 TypeScript 模組（`src/game/`），與畫面完全分離。

規格文件：[`04-sports-arcade/baseball-life.md`](../../04-sports-arcade/baseball-life.md)

## 世界種子碼

每一局由一組 8 碼種子（例：`64aa2bl7`）決定出身牌、骰運與所有隨機事件。

**相同種子碼 ＋ 相同選擇 ＝ 相同人生。** 把種子碼或 `?seed=64aa2bl7` 連結傳給朋友，就能在同樣的天賦下比較不同的走法。

決定論的實作重點：

- 每次擲骰都由 `hash(種子碼, 回合, 選擇次數, 用途)` 導出 **獨立亂數流**，而不是共用一條可變序列。分支消耗的亂數量不同也不會讓後續結果偏移。
- 選項洗牌使用 Fisher-Yates，不使用 `sort` 加隨機比較函式——後者的結果會隨 JavaScript 引擎的排序實作而改變。

## 玩法概要

| 階段 | 內容 |
|------|------|
| 高中 11 回合 | 每季選一項訓練；高一夏、高二夏、高二秋（黑豹旗）、高三夏為全國賽事 |
| 畢業選擇 | 中職選秀／大學／社會人／直接旅美 |
| 職業每年 1 回合 | 休賽期訓練 → 模擬整季成績 → 獎項、國際賽、傷病、交易、衰退 |
| 引退 | 生涯總結與名人堂積分 |

球員 **幾乎在 22 歲前就定型**（年齡成長係數 ≤18 歲 1.35、≤29 歲 0.22、33 歲後 0.03），所以高中三年才是真正的養成期。每項能力另有一個看不見的潛力上限，決定這一局的天花板。

八種隱藏特質（天才、鐵人、大器晚成、自律狂、國際賽之鬼、玻璃體質、全民英雄、青春的殘影）在達成條件時才會覺醒。

五種可選位置：投手、捕手、內野手、外野手、**二刀流**。二刀流十項能力一起練、每季產出打擊與投球兩份成績單，兩邊都課 0.72 的工作量稅，是難度最高的一條路。

投手的「變化球」不是直接練的，而是由 **球種庫**（滑球／曲球／指叉球／變速球／卡特球／伸卡球）推導出來——只靠一顆球路會明顯撞到天花板。

其他系統：

- **金錢**：簽約金、逐年談出來的年薪、人氣帶來的代言收入，全部以萬元計。
- **自由球員與交易**：中職滿 9 季取得 FA 資格，可轉隊、留隊或以自由身旅日；每季另有交易判定，因此一段生涯通常會效力 2–4 支球隊。
- **生涯里程碑**：通算 2000 安、300 轟、200 勝這類門檻，以及無安打比賽、完全比賽、完全打擊等單場壯舉。
- **隨機事件**：約 70 則，依階段與年齡分層，並優先抽還沒看過的。
- **分享卡**：總結頁以 canvas 產生一張 720×1000 的 PNG，含結局、關鍵數據、特質與種子碼，可直接下載。

## 本地開發（Dev Server）

在 repo 根目錄先安裝一次依賴（npm workspaces 會涵蓋所有遊戲）：

```bash
npm run setup
```

單獨開發此遊戲，在 `Games/Baseball-Life` 資料夾下執行：

```bash
npm run dev      # http://localhost:3000
npm run lint     # tsc --noEmit
npm run check    # 遊戲邏輯自我測試
npm run build    # 輸出到 dist/
```

或從根目錄建置後由統一的伺服器提供：

```bash
npm run build:game Baseball-Life
npm run dev      # http://localhost:3000 → 選單 → 進入遊戲
```

## 邏輯自我測試

`npm run check` 會把 `src/game/*.ts` 編成 CommonJS 後執行 `scripts/self-check.ts`，涵蓋：

- 相同種子碼 ＋ 相同選擇會重建完全相同的人生
- 不同種子碼、不同選擇都會產生不同結果
- 高中恰為 11 回合、畢業時 18 歲、共 4 場全國賽紀錄
- 四種守備位置 × 多組種子跑完整局後，所有數值都在合法範圍
- 生涯總結的加總與逐年成績一致
- 綜合能力只讀取該位置實際使用的能力
- 特質效果會相乘疊加
- 一次性決策（旅外邀請、自由球員、引退詢問）不會被重複詢問
- 收入只增不減，未打職業的生涯不會有任何收入，且認真經營的生涯收入高於擺爛的
- 每一項里程碑都對得上記錄簿，而且不會被重複登錄
- 交易與自由球員確實會讓球員換隊
- 事件池被抽完之前不會出現重複事件
- 二刀流每季都會留下打擊與投球兩份成績，且兩邊都計入通算
- 二刀流不會在每一組種子上都贏過專精一項（工作量稅有生效）
- 「變化球」始終等於球種庫推導的結果，球種不會被重複學習
- 衰退確實會削減球種，而不是被下一次同步還原
