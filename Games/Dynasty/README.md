## 球團王朝（Dynasty）

中職 **球團經營模擬**：接下一支球隊的總管職務，任期十年，在薪資帽、球迷熱度與董事會耐心之間建立王朝。

與《[棒球人生](../Baseball-Life/)》共用同一個虛構世界觀與數值骨架——同樣的六支球隊、同樣的聯盟基準值、同樣的能力權重。那款你是球員，這款你是那個決定要不要續約他的人。

規格文件：[`04-sports-arcade/dynasty.md`](../../04-sports-arcade/dynasty.md)

## 核心

**贏球要花錢，而錢來自贏球。** 球員資產會折舊（30 歲起逐年衰退且加重），所以每一份合約都是在賭一個人的下坡什麼時候開始。

兩個招牌機制：

**董事會期望協商** — 每年季前跟董事會談好期望值（重建／站穩／進季後賽／拚冠），年底照 **那個期望** 評分，而不是照勝場。往下調一級付出信任 −6，往上調一級當場 +4。這讓「重建」成為一條正當路線，而不是懲罰。

**球探報告的不確定性** — 你永遠看不到新秀的真實潛力，只看得到一個區間。球探預算讓區間收斂，但**永遠不會收斂到 0**，而且報告是有偏差的，大約每七份就有一份根本沒有涵蓋真相。你比對方多花的球探預算，就是交易桌上的資訊優勢。

## 一個球季

| 階段 | 決策 |
|------|------|
| 季前董事會 | 協商今年的期望 |
| 春訓 | 編訓練預算（節流／均衡／打線優先／農場優先） |
| 例行賽 ×4 段 | 每段丟出一個當下的情境，2–3 個選項各有代價 |
| 交易截止日 | 三份 AI 提案，可再詢價一輪 |
| 選秀 | 從八名新秀中指名一人，只有球探區間可參考 |
| 續約 | 到期合約：依行情、壓價（有機會談崩）或放走 |
| 季後預算 | 設定下季票價、行銷與球探 |

十年共約 100 個決策。信任連續兩年低於 20，或資金低於 −5,000 萬，任期提前結束。

## 例行賽為什麼重做了

第一版被回報「一點都不好玩」。量了一下就知道為什麼，而且不是平衡問題：

| | 初版 | 現在 |
|---|---|---|
| 一任十年的決策數 | 100 | 101 |
| 其中「例行賽區塊」 | **40（同一張四選一）** | 40（**32 種不同情境**） |
| 「知道了」關視窗的點擊 | **99** | **1** |
| 總點擊 | **199** | **102** |

三個發現：

**一、100 個決策裡有 40 個是同一個畫面**，而且第一個選項字面上寫著「維持現狀：不做調整」。**一個安全答案是「什麼都不做」的選擇，問四十次就不是選擇**，是包裝成選單的「下一步」按鈕。

**二、一半的互動是在關視窗。** 節奏是決定 → 讀報告 → 關掉 → 決定，199 次點擊裡 99 次是「知道了」。現在報告直接顯示在下一個決策的上方，不需要關。

**三、18 個事件一整任只觸發 4～5 次，而且不問你任何事。** 唯一會製造變化的內容，藏在球季結算的 45% 機率後面，出現時也只是報告裡的一行字。

改法是把例行賽區塊換成 **30 個情境**，由球隊的實際狀態抽出——王牌說手肘緊、二軍新秀打爆二軍、老將守不動了、贊助商要球員去拍廣告、球迷在場外拉白布條——而且 **每個選項都有代價**：不花錢就得付士氣、熱度或董事會信任。這條規則寫進了自我測試，加新情境時會被擋下來。

實測一任十年出現 **32 種不同開場**，情境會直接叫出你隊上球員的名字。

## 上一步

決策可以退回，最多 20 步。

**這不是重骰。** 引擎的每次隨機都以 `(用途, 年份, 階段, 區塊, 已做決策數)` 當種子，所以退回去再選 **同一個選項，結果一模一樣**——上一步修的是誤點，不是壞運氣。這條性質由自我測試釘住：同一個狀態解同一個選項兩次，現金、熱度、士氣、戰績與報告內容都必須完全相同。

## 本地開發

在 repo 根目錄先安裝一次依賴：

```bash
npm run setup
```

單獨開發此遊戲，在 `Games/Dynasty` 資料夾下：

```bash
npm run dev      # http://localhost:3000
npm run lint     # tsc --noEmit
npm run check    # 遊戲邏輯自我測試
npm run build    # 輸出到 dist/
```

## 邏輯自我測試

`npm run check` 涵蓋 16 項，其中幾項是在開發過程中真的抓到 bug 的：

- **沒有免費選項**：每個情境選項都必須至少動到一個數字，而且每個情境至少要有一個選項是有代價的。這條是例行賽改版的設計規則，寫成測試才不會在加新情境時被忘掉——它上線第一次跑就抓到 `merch-boom` 兩個選項都是純賺，我自己寫的
- **上一步不是重骰**：同一個狀態解同一個選項兩次，現金、熱度、士氣、聯盟戰績與報告內容都必須完全相同
- **情境要有變化**：一任十年至少出現 18 種不同情境，且未出現過的優先
- **相同種子碼 ＋ 相同決策會重建同一個十年**，不同種子與不同決策都會分歧
- **聯盟收支平衡**：每一勝都是別隊的一敗，全聯盟勝場數必須等於敗場數（原本各隊獨立模擬，十年下來聯盟多出 18 勝）
- **勝率曲線單調且在真實戰力區間內確實有鑑別度**（原本除數太小，稍強的球隊就全部貼在上限）
- **球探區間會隨預算收斂但不會歸零，且不會永遠涵蓋真相**（否則選秀就變成「每年選中位數最高的那個」的解題）
- 每季恰好 120 場、名次合法、每季都有結算
- 名單永遠合法：不超過 26 人、沒有重複球員、沒有人同時在兩隊
- 估值必須同時反映年齡與合約，不只是能力
- 綜合能力權重與《棒球人生》完全一致
