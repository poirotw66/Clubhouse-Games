    操作說明

    • ← → 或 A D：轉舵
    • Z / ↑：收帆（帆靠近中線，搶風時用）
    • X / ↓：放帆（帆打開，順風時用）
    • C 或 T：開關自動調帆（手動按 Z/X 會自動關閉）
    • 空白鍵：一鍵換舷（自動把船轉到風的另一側）
    • 拖曳畫面：環顧　·　R：重開

    右上風向盤：箭頭指「風吹來的方向」，上方是船首。紅色扇形是頂風區——指針進紅區就沒有推力，轉舵讓指針離開紅區。綠色閘門為下一檢查點，依序穿過即完賽。

    簡單模式（預設開啟）：「下一門」羅盤上會多一支綠色箭頭，那是建議航向——照著轉就對了。閘門在上風處時無法直接航向它，綠色箭頭會自動指出該走哪一側搶風，下方文字會顯示「搶風：左舷／右舷」。此模式下船也不會完全停住，隨時還能轉舵。關掉後只剩白色的閘門方向箭頭，需要自己判斷搶風角度。
