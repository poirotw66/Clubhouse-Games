How WebMCP works

  1. The page exposes structured food-building tools.
  2. An AI agent discovers those tools.
  3. The agent calls them with structured arguments.
  4. The shared BuilderEngine updates application state.
  5. The UI immediately reflects the same state.

Tools describe intent: pizza_add_topping({topping: "mushroom"}), not coordinates or selectors. Validation, pricing, undo, and rendering are identical for human and agent actions.

Everything runs locally in this tab. Orders are demo confirmations only. No server, payments, remote API, or network connection is required for the builder. Drafts last for this page session.
