製作一款俯視角、即時多人合作的輕量生存建造遊戲。

遊戲核心是一列「永遠不會停止前進的火車」。玩家必須在火車抵達軌道盡頭之前，不斷向前探索、採集資源並鋪設新的鐵軌，讓火車持續前進。

玩家可以自由分工：

* 砍樹取得木材
* 挖岩石取得礦石
* 將資源搬回火車
* 使用火車上的製作車廂，把木材與礦石加工成鐵軌
* 搬運並鋪設鐵軌
* 清除擋路的森林、岩石與障礙物
* 為火車補充必要資源，例如冷卻水或燃料

整個遊戲的主要壓力來自火車持續向前移動。玩家必須一邊規劃最佳路線，一邊快速取得資源。如果鋪路速度太慢，火車到達軌道盡頭，就會出軌並結束遊戲。

地圖採程序生成並持續向前延伸，包含森林、岩石、河流、狹窄通道與其他自然障礙。玩家需要決定是直接清除障礙、繞路，還是消耗特殊資源建立橋梁或其他通道。

地圖中的資源位置會迫使玩家短暫離開鐵路路線，因此玩家需要在「收集更多資源」與「趕快鋪下一段鐵軌」之間持續做取捨。

遊戲強調多人合作與混亂感。每個玩家沒有固定職業，但因為同一時間要完成很多事情，自然會形成分工。玩家可以互相搬運資源、接力運送物品，也可能因為擋路、拿錯物品或溝通失誤造成混亂。

隨著遊戲進行：

* 火車速度逐漸提高
* 地形更加困難
* 資源分布更加分散
* 玩家可以升級或增加不同功能的火車車廂
* 出現新的環境規則與特殊事件

遊戲沒有傳統關卡終點，核心目標是讓火車前進盡可能遠，並以距離、區域數量或抵達車站數作為成績。

視覺採色彩鮮明、簡化、低多邊形或可愛卡通風格，使用固定俯視斜角攝影機。畫面必須讓玩家能快速辨識樹木、石頭、資源、軌道、玩家與火車。

整體體驗應該是：
「規則非常容易理解，但因為火車永遠不停，所以玩家會從井然有序逐漸陷入手忙腳亂的合作混亂。」

最重要的設計原則：
玩家永遠知道下一步該做什麼，但永遠覺得時間不夠。
