# 西洋跳棋（Checkers / Draughts）

## 類別

棋盤類型

## 概述

西洋跳棋（Checkers，英式稱 Draughts）是兩人在格盤上進行的跳吃棋戲。棋子僅在深色格上斜向移動，可跳過對方一子並吃掉；若可連續跳吃則必須連續跳。兵到達對方底線升為「王」。先使對方無子或無法移動者勝。

## 人數與建議年齡

- 人數：2 人。
- 建議年齡：約 6 歲以上。

## 所需器材

- **棋盤**：8×8（美式）或 10×10（國際式）；僅用深色格。
- **棋子**：雙方各 12 枚（8×8）或 20 枚（10×10）。

## 遊戲目標

**吃掉對方全部棋子** 或 **使對方無法合法移動** 者獲勝；若雙方都無法取勝則和局。

## 規則說明

### 美式 8×8（American / English）

- 雙方各 12 枚放在己方前三排深色格；**黑方先手**。
- 兵斜向前一格；僅向前跳吃；王為短王（斜向一格任意方向）。
- 可吃則必須吃；多種吃法可任選（不強制最多吃）。

### 國際式 10×10（International / FMJD）

- 雙方各 20 枚放在己方前四排深色格；黑方先手。
- 兵可向前或向後跳吃；王為**飛王**（斜線任意格數移動與遠距跳吃）。
- 多種吃法時必須選擇**吃子數最多**的序列（majority capture）。

### 回合流程（共通）

1. 選子 → 落點（可預覽路徑）。
2. 連續跳吃必須跳完。
3. 兵到達對方底線升王。
4. 無合法移動的一方輸。

## 勝負條件

- 對方無子或無合法移動 → 己方勝。
- 美式 8×8 在雙方完美下法下已證明為和局。

## 數位版模式（Clubhouse）

本館實作路徑：[Games/Checkers/](../Games/Checkers/)，對照 [`docs/GAME-QUALITY-BAR.md`](../docs/GAME-QUALITY-BAR.md)：

| 項目 | 本實作 |
|------|--------|
| 模式／變體 | **美式 8×8**／**國際式 10×10（飛王）**；雙人／電腦名冊／系列賽／殘局謎題 |
| Replay hook | 連勝、最佳連勝、最大勝差、對手解鎖、謎題通關、系列賽勝場（`clubhouse-checkers:progress:v1`） |
| Undo／Hint | **悔棋**；**提示**（含著法理由） |
| Feedback | `ResultOverlay`＋覆盤；`synthAudio`（移動／吃子／連跳加分音）；滑動／跳吃動畫與吃子特效 |
| Touch | 選子／落點與工具列可觸控 |
| Check | `npm run check`（vitest；含規則變體、謎題 solver 驗證、名冊解鎖、系列賽） |

### 深度內容

1. **技巧表現**：強制吃／最多吃、飛王遠程路線、殘局步數限制。
2. **中期目標**：系列賽（兩／三／四勝制）；10 題「N 步內必勝」謎題（solver 驗證）。
3. **長期目標**：五名 CPU 對手解鎖階梯；謎題收集。
4. **對手個性**：菜鳥跳兵／衝鋒手／鐵壁衛／飛王師／館主冠軍（風格參數不同，非僅失誤率）。

### 提示與覆盤

- 提示會說明理由（例如「連跳 N 子」「避開被跳」「升王」）。
- 終局可開**覆盤**：標註佳手／漏招／失誤。

`localStorage` 鍵：`clubhouse-checkers:progress:v1`（會遷移舊的 streak key）。
