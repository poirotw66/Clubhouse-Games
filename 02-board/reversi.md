# 黑白棋（Reversi / Othello）

## 類別

棋盤類型

## 概述

黑白棋（Reversi，商業名 Othello）是兩人在 8×8 棋盤上進行的策略棋戲。雙方輪流放一枚己色棋子，若在直線（橫、豎、斜）上己方新子與另一枚己方子之間全是對方子，則將該線上的對方子全部翻成己色；終局時己色棋子多者勝。

## 人數與建議年齡

- 人數：2 人。
- 建議年齡：約 8 歲以上。

## 所需器材

- **棋盤**：8×8 格，僅用 64 格。
- **棋子**：64 枚，雙面一黑一白（或兩色），可翻面。

## 遊戲目標

在無法再下子時結束遊戲，**己色棋子數量多於對方** 者獲勝；若數量相同則和局。

## 規則說明

### 準備／設定（Othello 標準）

- 開局時棋盤中央 2×2 放四子：兩白在東北—西南對角，兩黑在西北—東南對角。**黑方先手**。

### 回合流程

1. 輪到的一方在 **空格** 上放一枚己色子（正面朝上）。
2. **合法下法**：新子必須與己方另一枚己色子形成「夾子」——即兩枚己色子之間（橫、豎或斜線）**全部** 為對方子；放子後將該直線上被夾住的 **所有對方子** 翻成己色。
3. 同一手可同時在 **多條直線** 上翻子（多方向夾住的都翻）。
4. **無合法手時** 輪到的一方必須 **放棄**，改由對方下；若雙方都無合法手則遊戲結束。
5. 通常 **不允許** 僅翻 0 枚的「虛手」；至少須翻 1 枚才算合法。

### 可行動作與限制

- 只能下在空格且下後至少翻轉對方 1 枚。
- 已放下的子之後可能再被對方翻過去，無「固定」一說。

### 特殊狀況

- **Pass**：若輪到的一方沒有任何可翻子的下法，必須 pass，對方繼續下。
- **終局**：64 格滿或雙方都無法下時，數子定勝負；空格常計入勝方（依賽規）。

## 勝負條件

- 終局時 **己色子數 > 對方子數** → 勝；相等 → 和。
- 競賽中若計時用盡（超時），常規為該局判負或依賽規處理。

### 深度設計（對照審查）

1. **核心創新四大機制（Innovative Sensory & Tactical Pillars）**：
   - **多米諾連鎖骨牌翻子波動（Domino Cascade Wave Flip）**：
     - 單步多方向翻子不再是生硬的一瞬間全部變色，而是從落子中心沿 8 方向射線依距離（Chebyshev distance）按波徑逐格微延遲翻轉（每級約 70ms）。
     - 每一波翻轉同步觸發五聲音階升音琶音（Pentatonic ascending scale），伴隨棋盤格色散微波漣漪。
     - 翻轉 3 子以上觸發動態 Combo 呼號（`⚡ 3 連翻連鎖！`、`🔥 5 連波大連鎖！`、`👑 8 翻巨浪大逆轉！`）與高連擊慶祝短曲。
   - **3D 擬真雙面雙色厚度棋子（3D Tactile Dual-Sided Discs with Drop Impact）**：
     - 正面黑曜漆面（Obsidian Lacquer）與反面象牙珍珠（Ivory Pearl），搭配同心觸覺凹槽、邊緣厚度立體倒角與反射高光。
     - 落子時具備物理彈性下墜衝擊（Drop Impact）與毛氈微震波環。
     - 翻面時以 CSS 3D `preserve-3d` 沿軸心旋轉 180° 並在半空中抬升，完整呈現正面反面即時轉向過渡，支援無障礙減敏動態（`prefers-reduced-motion`）。
   - **四角黃金要塞防禦光環與符文鎖定（Corner Golden Fortress Lock）**：
     - 佔據盤面四大角（A1、H1、A8、H8）時，觸發衝天而起的黃金光柱特效與金光要塞符文（`★要塞`）。
     - 播放專屬黃金三和弦琶音鍾鳴（`playGoldenFortressChime`），屏幕微震帶起金色紙花。
     - 佔領後該角成為永久不可逆安定基石，左翼要塞雷達發光常駐。
   - **戰術勢力熱圖與穩定度分析儀（Stability & Frontier Telemetry）**：
     - **永久安定子（Stable Discs）**：演算法深度追蹤四角與邊緣閉鎖鏈條，標記永遠無法被翻轉的安全子（透視模式下顯示金光盾牌 🛡️）。
     - **前線暴露率（Frontier Exposure Rate）**：即時計算外圍鄰近空格的棋子佔比（前線子過多易被對手藉助借力，暴露率過高觸發警戒色彩）。
     - **內部核心子（Interior Core Discs）**：計算八方皆被包圍的安全子數，呈現實質控制核心。

2. **雙翼戰術戰鬥座艙（Dual-wing Battle Station Cockpit）**：
   - **左翼・戰況遙測儀**：
     - **局勢天秤（Balance of Power）**：雙色子數動態佔有率比例條、開局／中盤／終局收官階段判定。
     - **四角要塞掌控儀（Corner Dominance Radar）**：A1、H1、A8、H8 四角實時佔領雷達與要塞符文鎖定。
     - **穩定度與前線暴露遙測（Stability Telemetry）**：雙方永久安定子數、前線暴露率與核心子分析。
     - **行動力壓制儀（Mobility Suppression Index）**：即時比對雙方可下步數，觸發「逼迫 PASS 警戒」、「全面壓制」或「機動告急」。
     - **戰術透視（Tactical Vision）**：即時熱圖徽章（顯示各合法手翻子數量 `+1`、`+3`…）、安定子金盾、前線暴露點與危險禁著點標籤（`★角`、`危X`、`慎C`）。
   - **中島・競賽棋盤**：標準國際代數座標（A-H、1-8），游標／懸停即時觸發**翻子連鎖光環預覽**與**準星戰術讀數**。
   - **右翼・情報與戰略庫**：
     - **作戰對手檔案（Dossier）**：風格雷達數值條（搶角慾望、機動壓制、翻子慾望、X位警戒）與對局情境語錄。
     - **系列賽戰況（Series Tracker）**：單局／三戰兩勝／五戰三勝即時比分。
     - **名宿四本柱戰術錦囊（Tactical Arsenal）**：摺疊式實戰要訣（安靜落子、角地鎖定、避開 C/X 位、奇偶終局）。
3. **實體鍵盤矩陣導航（Keyboard Matrix Navigation）**：
   - <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> / <kbd>↑</kbd><kbd>←</kbd><kbd>↓</kbd><kbd>→</kbd> 移動準星，<kbd>Space</kbd> / <kbd>Enter</kbd> 落子。
   - 快捷鍵：<kbd>T</kbd>（透視）、<kbd>H</kbd>（提示）、<kbd>Z</kbd>/<kbd>U</kbd>（悔棋）、<kbd>P</kbd>（Pass）、<kbd>?</kbd>（快捷鍵指南）。
4. **行動裝置戰術膠囊資訊列（Responsive Capsule Bar）**：
   - 窄螢幕自動切換為頂部緊湊膠囊列（天秤、四角、安定子、機動、透視快速開關）。
   - 點擊「戰情」可滑出完整戰情作戰室抽屜，兼顧極致操作手感與專業戰術分析。
5. **技巧表現**：角地／避開 X 格／機動／殘局奇偶；對局中顯示情境教學提示，終局複盤比對建議手。
6. **中期目標**：殘局謎題包（「黑／白先，N 手內取勝或最大化勝差」）、逐題解鎖與 ★★★；系列賽累積勝場。
7. **長期目標**：對手名冊解鎖階梯；謎題完成／星級寫入 localStorage。
8. **對手個性**：貪心小子、貼邊幽靈、搶角狂魔、流動舞者、謹慎學者、奇偶大師——各自有 `BotStyle` 權重（翻子慾、邊權、角慾、機動、X 格恐懼），不是同一機器人調失誤率。

### 殘局謎題

- 固定盤面 14 題，空格 ≤ 12，由 `solveExact` 驗證可達成目標。
- `ACCEPTABLE_FIRST_MOVES` 釘死每題可接受首手（唯一解或明確列出複數解）；測試比對 live 解算結果。
- **逐題解鎖**：第 1 題預設開放，通關後解鎖下一題。
- **星級**：通關給 1–3★（無提示且無悔棋＝3★；只用其一＝2★；兩者都用＝1★）；保留歷史最佳。
- 玩家偏離最佳線（無法維持目標）即失敗；對手以精確解應手。
- 提示鍵給出精確最佳手之一（會影響星級）。

### 對手名冊

- 依序挑戰；打贏目前前線對手後解鎖下一位。
- 可搭配系列賽長度。

`localStorage` 鍵：`clubhouse-reversi-win-streak`、`clubhouse-reversi-best-streak`、`clubhouse-reversi-best-margin`、`clubhouse-reversi-ladder`。

## 常見變體或可選規則

- **Anti-Reversi**：子少的一方贏。
- 開局四子擺法（經典 Othello 為固定斜線）。
- 時間限制、讀秒、違規處理等依賽事規定。
