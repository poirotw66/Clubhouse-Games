# 四子棋（Connect Four）

## 類別

棋盤類型

## 概述

四子棋（Connect Four，又稱 Four in a Row、四目並べ）是兩人輪流在直立格網中「投下」己色棋子，棋子會落在該列最低的空格；先在橫、豎或斜線連成目標長度者獲勝。若盤面填滿仍無人達標則和局。

Clubhouse 數位版在標準 7×6／連四之外，加入 **PopOut**、**五子勝**、**8×7／9×7 大盤**、**系列賽**、**對手個性**與 **謎題模式**，讓標準盤「先手已解」之後仍有可練的深度。

## 人數與建議年齡

- 人數：2 人（或 1 人對電腦／謎題）。
- 建議年齡：約 6 歲以上。
- 遊戲時間：單局約 5–15 分鐘；系列賽視先取勝場而定。

## 所需器材

- **棋盤**：直立式格網；數位版可選 7×6、8×7、9×7。
- **棋子**：兩種顏色，數量足以填滿半盤。

## 遊戲目標

在橫、豎或斜線上任一方向 **先連成目標長度的己色棋子** 者獲勝（經典／PopOut 為四；五子勝為五）；同時要阻止對方。盤滿無人達標則 **和局**。

## 規則說明

### 準備／設定

- 棋盤為空，雙方約定先手（通常紅方先下）。
- 可選規則變體、棋盤大小、系列賽「先取 N 勝」（2／3／5）。

### 回合流程（經典／五子勝）

1. 輪到的一方選擇 **一列**，將一枚己色棋子投入該列；棋子落在該列 **目前最低** 的空格。
2. 接著換對方選擇一列下子。
3. 任一方形成連續目標長度己色時，該方 **立即獲勝**。
4. 若盤面全部下滿仍無人達標，則 **和局**。

### PopOut

- 回合可改為 **取出** 己方位於該列 **最底格** 的棋子（不可取對方子）。
- 取出後，該列上方棋子受重力下墜一格。
- 重力後若己方達標則己勝；若僅對方達標則對方勝（雙方同時達標時，執行動作者勝）。

### 可行動作與限制

- 每回合 **只能下一枚或執行一次 PopOut**（依變體）。
- 投下只能選擇 **尚未滿格** 的列。
- 經典／五子勝不可移動或取出已下的棋子。

### 特殊狀況

- 同時形成兩條連線時，完成該手的一方獲勝。
- 數學上 7×6 標準四子棋已被證明：**先手若完美下法可必勝**（尤其中央開局）——因此數位版提供大盤、五子勝、PopOut 與謎題以維持挑戰。

## 勝負條件

- **達標連線** → 該方勝。
- **盤滿無達標** → 和局。
- **系列賽**：累計單局勝場，先取得 N 勝者勝出（和局不計分）。

## 數位版模式（Clubhouse）

### 對戰

- **雙人對戰**／**對戰電腦**（簡單／普通／困難）。
- **規則變體**：經典、PopOut、五子勝。
- **棋盤**：7×6、8×7、9×7（五子勝預設 9×7）。
- **系列賽**：先取 2／3／5 勝；進行中比分可續玩（`clubhouse:connect-four:match:v1`）。
- **對手個性**（與難度深度分開）：
  - **衝刺手**：偏中路與進攻。
  - **鐵壁**：優先擋殺。
  - **佈局師**：重雙殺，PopOut 時更愛重組。
- **作戰座艙與街機重力立架（Arcade Gravity Vertical Dropper & Tactical Radar）**：
  - **三大立架外觀主題**：提供 **賽博街機（Cyber Arcade）**、**晶透壓克力（Crystal Acrylic）** 與 **經典錦標賽（Tournament Classic）**，隨時以頂部選單、右翼工坊或 <kbd>T</kbd> 鍵切換，具備壓克力倒角高光、深邃圓孔槽與金屬包角。
  - **擬真多階重力撞擊音效**：使用 Web Audio API 原生合成器，依棋子落入孔槽深度（第 0 列至底層）即時調變重力加速度音調，呈現厚實機身低音沉擊、清脆壓克力敲擊與二次微彈跳回饋。
  - **致命殺局貫穿雷射（Threat Ray）**：當任一方形成三連子殺局時，動態雷射光束直接高亮貫穿關鍵孔位，並於絕殺落點標記戰術十字準心；當存在一擊必殺威脅時，低頻心跳音效（Lub-Dub Heartbeat）緊張搏動，可切換全時／僅致命點／關閉模式。
  - **終局連四勝利演出（Four-in-a-Row Overdrive）**：達成連四時激發霓虹金芒高亮相連的 Overdrive 雷射光束與環形光波。
  - **動態棋力即時評估（Dynamic Move Quality Feedback）**：落子即刻給予街機風格戰術評價徽章浮現演出（🏆 絕殺勝勢、🌟 雙殺神之一手、🛡️ 關鍵鐵壁、⚡ 先機銳攻、⚠️ 緩手失位、💀 致命失誤、🎯 穩健推進）。
  - **雙翼戰情座艙**：
    - **左翼優勢示波器（Advantage Oscilloscope）**：動態即時波形示波器描繪雙方勝率震盪波幅、即時盤面威脅情報、中路核心控制統計。
    - **右翼戰情檔案與工坊**：對手個性戰術解說、立架主題切換器、雷射模式設定、系列賽比分板與大師對弈心法。
  - **底部門閘釋放系統（Bottom Mechanical Release Gate）**：配備實體「開閘清盤」槓桿機構，點擊觸發彈簧機械鎖聲響，盤中棋子呈物理重力瀑布傾瀉墜入收納槽。
  - **手勢滑動投子與落點導軌雷射**：行動端支援直接於盤面滑動瞄準欄位並於離手時精準投子；懸停各列時具備垂直落點瞄準線與虛影導引。
- **實體鍵盤快捷支援**：
  - <kbd>1</kbd>～<kbd>7</kbd>／<kbd>9</kbd>：直接投子至對應直列。
  - <kbd>←</kbd>／<kbd>→</kbd> + <kbd>Space</kbd>／<kbd>Enter</kbd>：切換選列並落子。
  - <kbd>Z</kbd>／<kbd>Backspace</kbd>：悔棋。
  - <kbd>H</kbd>：提示。
  - <kbd>P</kbd>：切換 PopOut 模式。
  - <kbd>R</kbd>：開閘重新開局。
  - <kbd>T</kbd>：切換立架壓克力主題（賽博街機／晶透壓克力／經典錦標賽）。
  - <kbd>M</kbd>：靜音開關。
- **悔棋**、**提示**（以困難＋佈局師建議）。
- 手感：物理重力彈跳動畫、勝線金芒脈動；音效使用原生 Web Audio 機構合成器與 `@clubhouse/shared/synthAudio`。

### 謎題

- 約 10 題「N 步內取勝」固定盤面（含 PopOut、大盤、五子勝）。
- 破解進度存本機；可提示／悔棋。

### 存檔

- 戰績：`clubhouse:connect-four:stats:v1`（含總計、`byMode` 分桶連勝／勝負、系列賽、謎題數、上次設定）。
- **分桶鍵**：`變體:棋盤:難度`（例如 `popout:8x7:hard`）；連勝與戰績互不混淆。
- 系列賽中：`clubhouse:connect-four:match:v1`。
- 謎題：`clubhouse:connect-four:puzzles:v1`。
- **遷移**：若無新 key，會讀取舊版 `clubhouse-connect4-win-streak`／`clubhouse-connect4-best-streak` 並寫入新結構；舊版無 `byMode` 時，把總計歸入上次設定對應的桶；之後仍同步回寫舊 key 以相容舊建置。

### Check

- `npm run check`（vitest）：重力、連線、PopOut（含 AI 取勝 pop）、三檔難度、個性權重差異、系列賽、分模式戰績隔離、謎題主線可解。

## 常見變體或可選規則

- **PopOut**：可選擇從己方棋子所在的 **最底格** 移出一枚，該列上方棋子下墜一格。（已實作）
- **五子勝**：改為先連成五枚者勝（常用於 9 列×7 行等較大盤）。（已實作）
- 棋盤尺寸：5×4、8×7、8×8 等。（已實作 8×7／9×7）
