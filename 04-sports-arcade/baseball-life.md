# 棒球人生（Baseball Life）

## 類別

運動機檯類型（文字型生涯模擬）

## 概述

棒球人生（Baseball Life）是一款 **文字選項 ＋ 骰子 ＋ 能力養成** 的單人生涯模擬遊戲。玩家扮演一名 16 歲的高中球員，從高一春天入部開始，經歷三年高中生活、四場全國賽事、一次選秀，再走過職業球團、旅外挑戰、國際賽、傷病與衰退，最後在引退時接受名人堂票選的檢驗。

遊戲的核心不是操作，而是 **取捨**：每一個時期只能選一項訓練，練了打擊就練不了守備；大賽全力衝刺能換到人氣與成長，代價是疲勞與受傷風險；三十歲之後每一年的選擇都在跟身體賽跑。

每一局由一組 **世界種子碼** 決定。相同種子碼 ＋ 相同選擇 ＝ 相同人生，因此玩家可以交換種子碼，在同樣的天賦與骰運下比較不同的走法。

## 人數與建議年齡

- 人數：1 人。
- 建議年齡：約 10 歲以上（需閱讀文字並理解數值取捨）。

## 所需器材

- **世界種子碼**：8 碼英數字串（例：`64aa2bl7`），可由網址 `?seed=xxxxxxxx` 帶入或於標題畫面輸入。
- **球員卡**：姓名、守備位置（投手／捕手／內野手／外野手）、出身（由種子碼抽出三選一）。
- **能力面板**：五項位置能力 ＋ 四項狀態值。
- **選項卡**：每個時期 3–5 張，含訓練重點與預期成長方向。

## 遊戲目標

- **主線**：從高中入部走到引退，累積生涯成績。
- **評價**：引退時依生涯數據、獎項、國際賽與人氣計算 **名人堂積分**，得到六種結局之一。
- **重玩**：換種子碼、換位置、換走法，追求更高的積分與尚未解鎖的隱藏特質。

## 核心規則與機制

### 能力值

所有能力為 0–100，介面同時顯示 **等級**（S / A / B / C / D / E / F）與數值。

| 位置 | 能力項目 |
|------|----------|
| 投手 | 球速、控球、變化球、續航力、膽識 |
| 捕手／內野手／外野手 | 打擊、長打、跑壘、守備、選球 |

另有四項狀態值：

| 狀態 | 作用 |
|------|------|
| 體能 | 降低受傷機率，影響出賽數 |
| 心志 | 提高骰出高點數的機率，穩定大賽表現 |
| 人氣 | 影響選秀順位、旅外邀請與名人堂積分；每季自然衰退 10% |
| 疲勞 | 過高會壓低骰子點數並拉高受傷率 |

**潛力（隱藏）**：建立球員時，每項能力會依種子碼取得一個看不見的上限。越接近上限，訓練的邊際效果越低——這是每一局難度與天花板的真正來源，玩家永遠看不到這個數字。

### 時期與流程

| 階段 | 回合 |
|------|------|
| 高中 | 高一春／夏／秋／冬、高二春／夏／秋／冬、高三春／夏／秋，共 11 回合 |
| 畢業選擇 | 中職選秀／大學／社會人／直接旅美（需綜合 60 ＋ 人氣 45） |
| 業餘 | 大學至 22 歲、社會人至 21 歲，之後再次選秀 |
| 職業 | 每年 1 回合（休賽期訓練 → 模擬球季） |
| 結束 | 引退並產生生涯總結 |

其中 **高一夏、高二夏、高二秋（黑豹旗）、高三夏** 為全國賽事回合，選項改為比賽態度三選一。

### 骰子與成長

每個訓練回合擲一顆 **六面骰**，決定該次訓練的成效倍率：

| 點數 | 倍率 | 描述 |
|------|------|------|
| 1 | 0.15 | 完全抓不到感覺 |
| 2 | 0.55 | 有練到，但身體很沉 |
| 3 | 0.85 | 紮實但不驚喜 |
| 4 | 1.15 | 手感不錯 |
| 5 | 1.50 | 狀況很好 |
| 6 | 2.10 | 開竅了 |

疲勞高於 65 有機率讓點數 −1，心志高於 70 有機率讓點數 +1。

**年齡成長係數**：≤18 歲 1.35、≤21 歲 1.00、≤25 歲 0.50、≤29 歲 0.22、≤32 歲 0.08、之後 0.03。也就是說 **球員幾乎在 22 歲前就定型了**，高中三年才是真正的養成期。

### 球季模擬

出賽數由「綜合能力 − 聯盟基準」經 **邏輯斯曲線** 決定：與聯盟平均相當者是先發常規球員，差距 8 分以上者幾乎坐板凳。各聯盟基準值：

| 聯盟 | 基準 | 例行賽場次 |
|------|------|------------|
| 高中棒球聯賽 | 30 | 24 |
| 大學棒球聯賽 | 41 | 40 |
| 成棒社會組 | 45 | 45 |
| 中華職棒 | 52 | 120 |
| 小聯盟 | 58 | 130 |
| 日本職棒 | 63 | 143 |
| 美國大聯盟 | 71 | 162 |

- **野手**：打率由打擊與選球決定，全壘打率由長打的 2.3 次方決定，盜壘由跑壘決定。
- **投手**：續航力 ≥52 為先發，否則為後援；防禦率由球速、控球、變化球的加權決定。
- 依成績隨機頒發打擊王、全壘打王、打點王、盜壘王、金手套、防禦率王、勝投王、三振王、救援王、最佳十人、年度 MVP、新人王。

### 傷病

- 每回合依疲勞、體能、年齡與訓練強度判定；高中 3.5% 起跳，職業 6.5% 起跳。
- **輕傷**（腿後肌拉傷、手腕挫傷）只影響當季出賽，不扣能力。
- **重傷**（腰椎椎間盤突出、肩膀旋轉肌撕裂）扣能力並缺席一季。
- **生涯級**（Tommy John 手術、阿基里斯腱斷裂）扣更多能力，且高中階段不會發生。

### 衰退與退場

- 30 歲起（覺醒「自律狂」則延後至 32 歲）每年扣減能力，且逐年加重。
- 球團要求的門檻 **隨年齡上升**：`聯盟基準 − 6 ＋ (年齡 − 28) × 2`。連續兩季達不到即不再獲得合約。
- 31 歲後在特定條件下會主動詢問是否引退；39 歲球季結束強制引退。

### 隱藏特質

達成條件時自動覺醒，覺醒前完全不提示：

| 特質 | 條件 | 效果 |
|------|------|------|
| 天才 | 22 歲前骰出 12 次 6 | 成長 ×1.35，能力上限 +8 |
| 鐵人 | 連續 5 季全勤未進傷兵 | 衰退 ×0.7，受傷率 ×0.75 |
| 大器晚成 | 25 歲時綜合能力低於 62 | 成長 ×1.25 |
| 自律狂 | 累計 8 次選擇調整與自主訓練 | 衰退 ×0.5，衰退起點延後 |
| 國際賽之鬼 | 3 次國際賽繳出好表現 | 大場面表現 ×1.2 |
| 玻璃體質 | 生涯累計 3 次傷病 | 受傷率 ×1.6 |
| 全民英雄 | 人氣達到 90 | 人氣獲得 ×1.5 |
| 青春的殘影 | 高中拿下 2 座全國賽冠軍 | 大場面表現 ×1.1 |

### 名人堂積分與結局

積分 ＝ 打擊項（安打 ×0.35、全壘打 ×1.7、打點 ×0.3、盜壘 ×0.35）＋ 投球項（勝 ×8、三振 ×0.4、救援 ×4）＋ 獎項 ×26 ＋ MVP ×55 ＋ 人氣 ×2.2 ＋ 國際賽好表現 ×30 ＋ 聯盟強度加成。

| 積分 | 結局 |
|------|------|
| ≥ 2200 | 名人堂首輪高票入選 |
| ≥ 1450 | 名人堂入選 |
| ≥ 850 | 名人堂票選邊緣 |
| ≥ 380 | 稱職的職業球員 |
| 有職業球季 | 短暫的職業生涯 |
| 無職業球季 | 未竟的棒球夢 |

## 決定論與分享

- 每一次擲骰都由 `hash(種子碼, 回合, 選擇次數, 用途)` 導出獨立亂數流，而非單一可變序列。因此即使不同分支消耗的亂數量不同，**相同種子碼 ＋ 相同選擇仍會得到完全相同的人生**。
- 訓練選項的洗牌使用 Fisher-Yates，不使用 `sort` 加隨機比較函式，以免結果隨 JavaScript 引擎的排序實作而改變。
- 生涯總結提供「複製種子碼與連結」，連結格式為 `?seed=<種子碼>`。

## 存檔

- 每回合結束自動存入 `localStorage`（鍵名 `clubhouse:baseball-life:save`），關掉分頁不會損失進度。
- 引退後寫入歷代球員名冊（`clubhouse:baseball-life:archive`，保留最近 20 位），於標題畫面顯示。

## 操作與介面

- 單欄行動版優先，寬螢幕時左側固定能力面板、右側為選項與日誌。
- 所有可點擊元素最小 44×44 px。
- 骰子結果有落下動畫，`prefers-reduced-motion` 時停用。
- 深色主題，能力等級以顏色區分；疲勞採用獨立的紅／黃／綠標示，避免與「數值越高越好」的等級色混淆。
