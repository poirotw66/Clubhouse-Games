# 球團王朝（Dynasty）

## 類別

運動機檯類型（文字型球團經營模擬）

> 與《[棒球人生](baseball-life.md)》共用同一個虛構世界觀與數值骨架：同樣的六支中職球隊、同樣的聯盟基準值、同樣的能力模型。那款遊戲你是球員，這款你是那個決定要不要續約他的人。

## 概述

球團王朝（Dynasty）是一款 **單人球團經營模擬**。玩家接下一支中華職棒球隊的總管職務，任期十個球季，目標是在不把球團搞破產的前提下建立王朝。

核心不是「把數值練大」，而是 **在有限資金、有限薪資空間、有限耐心之下做取捨**：贏球要花錢，而錢來自贏球。你可以砸鍋賣鐵拚眼前這一年，也可以賣掉當家球星換一批看不清楚的新秀——但董事會的耐心是有限的，而且會記帳。

一局由一組 **世界種子碼** 決定：聯盟初始名單、每年的選秀梯隊、球員成長與所有隨機事件。相同種子碼 ＋ 相同決策 ＝ 相同的十年。

## 人數與建議年齡

- 人數：1 人。
- 建議年齡：約 12 歲以上（需要閱讀報表並理解多資源取捨）。

## 所需器材

- **世界種子碼**：8 碼英數字串，可由網址 `?seed=` 帶入。
- **球團**：六支中職球隊擇一（南方猛獅、桃園天使、台中巨砲、台南飛鷹、新北海豚、高雄火山），初始戰力與財務狀況不同。
- **球員名單**：一軍 26 人、二軍（農場）最多 20 人。
- **決策介面**：每個階段 2–6 個選項或數值滑桿。

## 遊戲目標

- **主線**：十個球季的任期內，盡可能累積總冠軍、季後賽資格與健康的財務。
- **失敗**：董事會信任連續兩年低於 20 即遭解僱，任期提前結束。
- **評價**：任期結束時依冠軍數、季後賽次數、累積盈餘、球迷熱度與自行培養出的球星，給出六種結局之一。

## 核心規則與機制

### 任期與董事會

玩家的任期是 **十個球季**。每個球季結束時，董事會依照 **年初協商好的期望值** 評分，而不是單純看勝場。

| 期望 | 達成條件 | 信任變化 | 資金變化 |
|------|----------|----------|----------|
| 重建 | 三年內讓 3 名自家新秀成為一軍主力 | 達成 +12／未達 −10 | 允許虧損上限放寬 3,000 萬 |
| 站穩 | 勝率 .500 以上 | +10／−12 | — |
| 進季後賽 | 取得季後賽資格 | +16／−15 | 達成時 +2,000 萬 |
| 拚冠 | 拿下總冠軍 | +28／−20 | 達成時 +6,000 萬 |

每年季前可以與董事會 **協商期望**：往下調一級要付出信任 −6，往上調一級當場 +4。這讓「重建」成為一條正當路線，而不是單純的懲罰——這是本作最重要的一個設計決定。

**信任**每年另有修正：獲利 +4／虧損 −6、球迷熱度 70 以上 +3／30 以下 −4。信任 < 20 連續兩年即解僱。

### 資源

| 資源 | 初始 | 說明 |
|------|------|------|
| 資金 | 8,000 萬 | 以萬元計。可為負，但負超過 −5,000 萬直接解僱 |
| 薪資空間 | 18,000 萬（軟性） | 超出部分課 **50% 奢侈稅**，於季末結算 |
| 球迷熱度 | 50 | 0–100。驅動門票與週邊收入 |
| 董事會信任 | 60 | 0–100。低於 20 連兩年解僱 |
| 農場等級 | 2 | 1–5。影響新秀成長速度與球探報告精度 |

### 球員與能力

沿用《棒球人生》的能力模型（0–100，顯示 S/A/B/C/D/E/F 等級）：

- **野手**：打擊、長打、跑壘、守備、選球
- **投手**：球速、控球、變化球、續航力、膽識

每名球員另有：**年齡**、**隱藏潛力**、**年薪**、**合約剩餘年數**、**傷病狀態**。

成長與衰退比照《棒球人生》：22 歲前是主要成長期，30 歲起逐年衰退且逐年加重。因此**球員資產是會折舊的**，這是所有交易決策的底層邏輯。

### 賽季流程

一個球季分為五個階段，共約 6 個決策點：

1. **季前（春訓）**
   - 與董事會協商期望
   - 分配訓練預算至五個部門：打擊、投手、守備、體能、農場（總額自訂，直接扣資金）
   - 編排一軍名單（26 人）與先發輪值
2. **例行賽**：120 場分成 **4 個區塊**（各 30 場）模擬。每個區塊結束顯示戰績與傷病，並允許一次調整：升降二軍、輪休疲勞球員、調整戰術傾向（保守／積極）
3. **交易截止日**：於第 3 區塊後觸發，出現 3 份交易提案
4. **季後賽**：前 4 名晉級，三輪制模擬
5. **季後**
   - 選秀（3 輪有意義的指名 + 其餘自動）
   - 合約續約與自由球員市場
   - 設定下季票價、行銷預算、球場與農場升級

### 球探與選秀（招牌機制之一）

**你永遠看不到新秀的真實潛力。**

球探報告顯示的是一個 **區間**，例如「潛力 C–A」。花在球探上的預算會讓區間收斂：

| 球探預算（每人） | 區間寬度 |
|------------------|----------|
| 0 萬 | ±25 |
| 200 萬 | ±16 |
| 500 萬 | ±10 |
| 1,000 萬 | ±5 |

區間永遠 **不會收斂到 0**。第一指名可能是廢物，第五輪可能是未來的名人堂，而你只能用機率下注。這與《棒球人生》裡「玩家看不到自己的潛力上限」是同一個設計哲學的兩面。

選秀順位為戰績倒序。每年梯隊由種子碼決定，因此「今年這批新秀值不值得為了選秀順位擺爛」是一個可以被實際推算的問題。

### 交易

採 **提案制** 而非自由組合：交易截止日與季後各出現 3 份由 AI 球團提出的提案，並標示對方的動機（爭冠、重建、清薪資）。玩家也可以花 300 萬「詢價」重新生成一批提案。

AI 對球員的估值：

```
價值 = 綜合能力 × 年齡係數 × 合約係數
年齡係數：≤23 歲 1.35、24–27 歲 1.15、28–30 歲 1.0、31–33 歲 0.7、34 歲以上 0.4
合約係數：年薪 / 該能力的市場行情，越划算越高（0.6–1.4）
```

新秀因潛力區間而估值模糊，**這正是交易能賺到差價的地方**：你比對方多花的球探預算，就是你的資訊優勢。

### 自由球員與合約

- 合約到期球員會提出續約要求（依能力與年齡計算），可接受、還價（有機率破局）或放走。
- 放走時若該球員能力高於聯盟基準，可獲得下年度的補償選秀籤。
- 自由球員市場每年 4–8 人，採 **暗標**：玩家出價，AI 球團同時出價，最高者得。出價過高會擠壓未來的薪資空間。

### 農場

農場等級（1–5）影響三件事：新秀每年成長量、球探報告精度加成、二軍可容納人數。

升級費用：`等級 × 2,500 萬`，且需一整季才生效。

**提前升上一軍會傷害成長**：21 歲以下的新秀在一軍出賽，該季成長量 ×0.5。急著補洞就要付出未來的代價。

### 營收模型

以萬元計，季末結算。

**收入**

| 來源 | 公式 |
|------|------|
| 門票 | `場均觀眾 × 票價 × 60 場 ÷ 10000` |
| 週邊 | `球迷熱度 × 明星球員數 × 12` |
| 轉播與聯盟分潤 | 固定 3,500 ＋ 勝場 × 25 |
| 贊助 | `球迷熱度 × 45`，奪冠當年 ×1.5 |

其中：

```
場均觀眾 = (3000 + 球迷熱度 × 90 + 上季勝場 × 45) × 票價彈性
票價彈性 = clamp(1.35 − 票價 / 900, 0.45, 1.15)   // 票價區間 200–600 元
```

票價調高單價但趕走觀眾，也會壓低球迷熱度（每高於 350 元的 50 元扣 2 點熱度）。

**支出**：球員薪資總額、奢侈稅、訓練預算、球探預算、行銷預算、農場維護（`農場等級 × 600`）、球場維護（固定 1,200）。

**球迷熱度**每年變動：`+ (勝率 − .500) × 120 + 季後賽 8 + 冠軍 20 − 自然衰退 10%`。

### 比賽模擬

不逐打席模擬。以陣容推導球隊強度，再以邏輯斯曲線轉為勝率：

```
打線強度 = 一軍前 9 名野手綜合能力的加權平均（先發權重較高）
投手強度 = 前 5 名先發 × 0.65 + 前 5 名後援 × 0.35
球隊強度 = 打線強度 × 0.5 + 投手強度 × 0.5 + 訓練加成 + 士氣修正
勝率 = 1 / (1 + e^-((球隊強度 − 聯盟平均) / 6))，clamp 0.25–0.75
單區塊勝場 = 30 × 勝率 + 常態雜訊
```

季後賽為三戰兩勝／五戰三勝，單場勝率同樣由雙方強度導出但 **向 .500 收斂**（短期系列賽的隨機性遠高於例行賽），這讓「例行賽第一但季後賽被淘汰」成為會真的發生的事。

### 隨機事件

每個區塊與每個季後階段各有機率觸發，事件池依 **球團處境分層**（爭冠、重建、財務吃緊、剛奪冠）：

- 當家球星要求提前續約，否則明年跳脫合約
- 明星投手手肘不適，可選擇讓他休息（少 5 勝）或硬撐（30% 機率報銷兩季）
- 母企業財務調整，資金一次性 ±3,000 萬
- 颱風取消 4 場主場比賽
- 二軍教練被挖角，農場等級 −1
- 球迷抗議票價，熱度 −8
- 新秀爆發，潛力區間上緣被大幅上修
- 聯盟簽下新轉播約，全隊分潤提高

事件優先抽 **尚未看過的**，抽完才允許重複——與《棒球人生》相同的處理。

### 結局與評價

任期結束（十季屆滿或遭解僱）後計算 **王朝分數**：

```
王朝分數 = 總冠軍 × 350 + 季後賽 × 90 + 累積盈餘 ÷ 40
         + 自行培養並成為聯盟頂級的球員 × 60 + 最終球迷熱度 × 3
```

| 分數 | 結局 |
|------|------|
| ≥ 1800 | 王朝締造者 |
| ≥ 1200 | 名總管 |
| ≥ 700 | 稱職的經營者 |
| ≥ 350 | 平淡的十年 |
| 完成任期但低於 350 | 被時代淘汰 |
| 遭解僱 | 中途下車 |

## 決定論與分享

與《棒球人生》採用相同的做法：每一次擲骰都由 `hash(種子碼, 球季, 階段, 決策次數, 用途)` 導出 **獨立亂數流**，而非共用一條可變序列。因此不同分支消耗的亂數量不同也不會讓後續偏移，**相同種子碼 ＋ 相同決策 ＝ 相同的十年**。

所有洗牌使用 Fisher-Yates，不使用 `sort` 加隨機比較函式。

初始名單、每年選秀梯隊、AI 球團的補強傾向全部由種子碼生成，因此玩家可以交換種子碼，比較同一個聯盟環境下的不同經營路線。

## 存檔

- 每個決策點自動存入 `localStorage`（`clubhouse:dynasty:save`）。
- 任期結束後寫入歷代總管名冊，標題畫面顯示。
- 成就進度獨立存放，跨局累積（比照《棒球人生》，且同樣完全不影響模擬結果）。

## 操作與介面

- 行動版優先單欄；寬螢幕時左側為球團儀表板（資金、薪資、熱度、信任），右側為當前決策。
- 常駐可展開的 **名單頁**（一軍／二軍分頁，可排序）與 **財務頁**（收支明細）。
- 鍵盤：數字鍵選擇選項、<kbd>Enter</kbd> 繼續、<kbd>R</kbd> 開關名單頁。
- 所有可點擊元素最小 44×44 px。
- 深色主題，沿用《棒球人生》的等級色與紅／黃／綠狀態色。

## 實作範圍建議

為避免範圍失控，第一版刻意 **不做** 以下項目：自由組合的交易介面（改為提案制）、逐打席模擬、球員個別談判對話、多國聯盟。

模組切分（純 TypeScript，與畫面完全分離）：

```
src/game/
  types.ts        狀態與資料結構
  rng.ts          種子與獨立亂數流（可直接沿用棒球人生）
  players.ts      球員生成、成長、衰退、估值
  roster.ts       名單、輪值、強度計算
  season.ts       例行賽與季後賽模擬
  finance.ts      營收、支出、奢侈稅
  scouting.ts     球探報告區間與選秀梯隊
  trades.ts       AI 提案生成與估值
  events.ts       隨機事件池
  board.ts        期望協商與信任評分
  engine.ts       階段推進與決策解析
```
