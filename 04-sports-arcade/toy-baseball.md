# 玩具棒球（Toy Baseball）

## 類別

運動機檯類型

## 概述

玩具棒球為單人對電腦的機檯棒球小遊戲。打者須在適當時機揮棒並選擇擊球方向；投球半局則選擇球種與進壘點，**出手後可微調軌跡**。正規賽可選 **3／6／9 局**比總分，或改打 **全壘打大賽**（限次揮擊），另有 **球季模式**（四隊循環＋冠軍賽）。

本館實作為 **1 對電腦**，含六種球路、九人守備、分局計分板、三角難度、具名對手配球傾向、球場因素、擊球手感（震動／停格／粒子）、首局引導、分難度生涯紀錄、球季存檔、觸控按鍵、`ResultOverlay` 與合成音效。

## 人數與建議年齡

- 人數：1 人（對電腦）。
- 建議年齡：約 6 歲以上。

## 所需器材與操作

- **雙翼復古球場座艙（Tabletop Ballpark Cockpit）**：
  - **中央主球場**：Canvas 球場（九位野手、即時跑者動態、打者架棒短打姿態）、分局逐局計分板、好壞球／出局數燈號、壘包狀態。
  - **左翼（戰術遙測儀 StatCast Telemetry）**：即時球路與轉速雷達（km/h 球速、RPM 轉速、水平橫移與縱向下墜 cm）、九宮格好球帶投打落點熱圖（逐球編號與好壞球標記）、StatCast 擊球初速（Exit Velo）、發射仰角（Launch Angle）與 Barrel 甜蜜擊球評等。
  - **右翼（戰略情資儀 Dugout Dossier）**：對手投手球種風格與破綻檔案、守備陣型指示（常規／拉打防堵／深遠警戒）、得點圈（RISP）動能警報、戰術指揮所（觸擊短打／戰術盜壘）、球場規格係數。
  - **行動端戰術速報條（Tactical Quick Strip）**：手機與窄螢幕自動折疊為頂級速報條與抽屜式情報面板，支援一鍵即時查閱九宮格熱圖與情資。
- **打擊與戰術操作**：
  - 空白鍵 <kbd>Space</kbd>：揮棒擊球。
  - 方向鍵 <kbd>←</kbd> <kbd>→</kbd>（或 <kbd>↑</kbd>／<kbd>↓</kbd> 中路）：調整拉打／推打／中路擊球方向。
  - 觸擊短打 <kbd>B</kbd>（或觸控短打按鈕）：切換架棒短打姿態，碰球轉化為內野滾地球，推進壘上跑者或強迫取分；高接觸品質可形成突襲短打安打。
  - 戰術盜壘 <kbd>S</kbd>（或觸控盜壘按鈕）：一、二壘有跑者時啟動，依投手球種（慢速變化球優勢大）、捕手阻殺與進壘點判定盜壘成功或阻殺出局。
- **投球**：六種球路（速／曲／滑／變／伸／叉）× 左／中／右進壘點；出手後約 0.28 秒內 <kbd>←</kbd> <kbd>→</kbd> 控球拐彎。
- **首局引導**：首次開啟顯示三步上手疊層（`clubhouse-toy-baseball-howto-seen`）；選單可再開「操作教學」。

## 遊戲目標

**正規賽**：選定局數結束後 **總分高** 者勝（含再見安打提前結束）。**全壘打大賽**：在限定揮擊次數內轟出最多全壘打。

### 模式與流程

| 項目 | 本實作 |
|------|--------|
| 對戰 | 固定 1P vs CPU（無雙人同機） |
| 正規賽 | 客場（玩家）先打；每半局三出局換邊；可選 3／6／9 局；逐局計分板 |
| 球季模式 | `season.ts`＋`teams.ts`：四隊循環賽＋冠軍賽；戰績表；`localStorage` 可中斷續玩；各球場外野深度／空檔係數 |
| 具名對手 | 每隊代表投手（快速球／變化球／引誘型）配球權重不同，打擊時顯示配球習慣提示 |

| 投球 | `pitching.ts`：六球種速度／橫移／下墜／控球幅度；CPU 依好壞球數＋對手傾向配球 |
| 守備 | `fielding.ts`：九野手＋陣型（一般／拉打／深守）；落點 vs 到位時間；球場圍籬距離可覆寫 |
| 打擊判定 | 本壘相對時機 × 方向 × 接觸品質 → 方向與力量；種子 RNG（`rng.ts`） |
| 打擊手感 | `hitFeel.ts`：依接觸品質震動／短暫停格／塵土與火花粒子；尊重 `prefers-reduced-motion` |
| 雙翼座艙 | 雙翼復古球場座艙：左翼 StatCast 遙測儀（球速／轉速／九宮格落點熱圖／擊球初速與仰角）＋右翼戰略情資儀（投手檔案／守備陣型／得點圈動能／球場規格）＋行動端速報條 |

| 戰績 | `localStorage` 分難度記錄勝場／連勝／得分／最長勝場局數與 derby 最佳（`stats.ts`）；球季另存 `clubhouse-toy-baseball-season-v1` |

### AI 難度（`Difficulty`）

| id | 標籤 | 體感（UI 短述） | 行為概要 |
|----|------|-----------------|----------|
| easy | 簡單 | 好球帶寬，對手常揮空，球種較好讀 | 寬打擊窗、CPU 瞄準差／常揮空、辨識球種差 |
| normal | 普通 | 配球有套路，往空檔打才容易安打 | 平衡窗口；兩好球後偏變速／叉球 |
| hard | 困難 | 窗口窄，對手少失誤，配球更刁鑽 | 窄窗口、高辨識率、角落配球、守備陣型更常移位 |

三檔以 `hitRadius`／`cpuAimSkill`／`cpuSwingRate`／`cpuTakeBall`／`cpuAimDir`／投球延遲／守備陣型機率拉開；`npm run check` 釘住順序、球種、空檔判定與短述唯一。

## 規則說明（本館）

### 準備／設定

1. 選模式（正規賽／球季模式／全壘打大賽）、局數（正規賽與球季）、難度（見 UI 短述）、右打／左打。
2. 首次進入顯示首局引導；按「知道了」後寫入本機。
3. 「開始比賽／開打球季／大賽」進入對戰或球季戰績表。

### 球季模式

1. 四隊（玩具猛虎＋三支具名對手）打單循環；玩家每場客場先打。
2. 對手各有球場因素（外野深／淺）與投手配球習慣；打擊時可看提示並從尾跡讀球。
3. 循環結束後前二名打冠軍賽；未晉級則自動模擬他隊決勝。
4. 戰績與賽程寫入本機，可中斷後「續玩球季」。

### 正規賽流程

1. **上半局（你打）**：CPU 依球數配球；看軌跡讀球種後揮棒並對準方向 → 依落點與野手到位判結果；三出局換邊。
2. **下半局（你投）**：選球種與進壘點，出手後短時間內左右控球；CPU 依難度決定是否揮棒與是否讀到球種。
3. **得分**：跑者踏本壘得 1 分；全壘打時壘上與打者皆得分；計分板記錄逐局得分。
4. **結算**：滿選定局數後比總分；末局下半主隊超前即結束（再見）；同分為和（連勝歸零）。

### 全壘打大賽

1. 僅打擊；共 10 次揮擊機會。
2. 全壘打計入本場支數與最遠距離；用盡揮擊後結算。

## 勝負條件

- **正規賽**：總分高者勝；同分為和。
- **全壘打大賽**：比全壘打數（展示最遠距離與生涯最佳）。
