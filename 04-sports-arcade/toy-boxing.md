# 玩具拳擊（Toy Boxing）

## 類別

運動機檯類型

## 概述

玩具拳擊為單人對電腦的機檯拳擊小遊戲。雙方在擂台上移動、出拳、格擋與閃避；有效擊中扣對方體力並計分。**三回合制**，每回合 60 秒；任一方體力歸零即 KO，否則比總分。

本館實作為 **1 對電腦**，含四名玩具角色、三角難度（體感短述）、首局引導、生涯戰績、觸控按鍵、`ResultOverlay` 與合成音效。

## 人數與建議年齡

- 人數：1 人（對電腦）。
- 建議年齡：約 8 歲以上（輕微暴力模擬）。

## 所需器材與操作

- **擂台／介面**：Canvas 擂台、雙方體力／耐力／必殺條、分數與回合計時。
- **鍵盤**：A／D 左右移動；J 刺拳、K 勾拳；S 格擋、W 閃避、I 撥招；L 必殺（能量滿）。
- **觸控**：對戰中顯示左右與各動作按鈕（`TouchButton`）。
- **首局引導**：首次開啟顯示三步上手疊層（`clubhouse-toy-boxing-howto-seen`）；選單可再開「操作教學」。

## 遊戲目標

有效擊中對手以扣體力並累積分數；**KO**（對方體力歸零）或 **三回合結束後總分較高** 者勝。

### 模式與流程

| 項目 | 本實作 |
|------|--------|
| 對戰 | 固定 1P vs CPU（無雙人同機） |
| 回合 | 最多 3 回合，每回合 60 秒；回合間恢復約 30% 體力 |
| 勝負 | KO 立即結束；否則比累計分數；同分為和 |
| 角色 | 藍拳機器人／紅絨熊仔／閃電兔／鐵拳恐龍（能力值略有差異） |
| 戰績 | `localStorage` 分難度記錄勝／負／和與連勝（`stats.ts`） |

### AI 難度（`Difficulty`）

| id | 標籤 | 體感（UI 短述） | 行為概要 |
|----|------|-----------------|----------|
| easy | 簡單 | 反應慢，常揮空 | 低反應／高失誤、思考慢、少撥招 |
| normal | 普通 | 會擋會攻，中規中矩 | 平衡攻防與思考節奏 |
| hard | 困難 | 高壓逼近，常撥招反擊 | 高反應／低失誤、逼近距離、常撥招 |

三檔以 `reactChance`／`mistakeChance`／`parryShare`／思考間隔拉開；`npm run check` 釘住順序與「困難明顯比簡單更能擋來拳」。

## 規則說明（本館）

### 準備／設定

1. 選自己的玩具與對手、選難度（見 UI 短述）。
2. 首次進入顯示首局引導；按「知道了」後寫入本機。
3. 「開始對戰」後倒數進入第 1 回合。

### 回合流程

1. **移動與出拳**：靠近對手後 J／K 出拳；擊中扣體力並加分。
2. **防禦**：S 格擋減傷、W 閃避、I 撥招（時機對可反制）。
3. **必殺**：紫色能量滿後 L 放出較強攻擊。
4. **回合結束**：時間到進入「下一回合」；第 3 回合結束或任一方體力歸零則結算。
5. **KO**：體力歸零顯示 K.O.，該方負。

## 勝負條件

- **KO**：對方體力歸零 → 勝。
- **判定**：三回合後 **總分高** 者勝。
- **平手**：總分相同 → 和局（計入戰績 draws）。

## 常見變體（規格背景，本館未實作）

- 故事模式、雙人同機、犯規／讀秒起身等完整拳擊規則。
