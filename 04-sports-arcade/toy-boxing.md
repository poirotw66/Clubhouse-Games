# 玩具拳擊（Toy Boxing）

## 類別

運動機檯類型

## 概述

玩具拳擊為單人對電腦的機檯拳擊小遊戲。雙方在擂台上移動、出拳、格擋與閃避；有效擊中扣對方體力並計分。**三回合制**，每回合 60 秒；任一方體力歸零或暈眩條滿即 KO，否則比總分。

本館實作為 **1 對電腦**，含四名可選玩具、**六位聯賽對手**（風格／招牌拳不同）、上／下段心機戰、預備動作可讀、自由對戰三角難度、首局引導、生涯與聯賽進度存檔、觸控按鍵、`ResultOverlay` 與合成音效（含打擊／撥招）。

## 人數與建議年齡

- 人數：1 人（對電腦）。
- 建議年齡：約 8 歲以上（輕微暴力模擬）。

## 所需器材與操作

- **擂台／介面**：Canvas 擂台、雙方體力／耐力／暈眩／必殺條、分數與回合計時。
- **鍵盤**：A／D 左右；↓ 或 C 下段；J 刺拳、K 勾拳（段位跟隨↓）；S 格擋（段位跟隨↓）、W 閃避、I 撥招（須對段）；L 招牌拳（能量滿，長預備、無法格擋、可閃避）。
- **觸控**：對戰中顯示左右、下段與各動作按鈕（`TouchButton`）。
- **首局引導**：首次開啟顯示上手疊層（`clubhouse-toy-boxing-howto-seen`）；選單可再開「操作教學」。

## 遊戲目標

有效擊中對手以扣體力並累積分數。兩條主要勝利路線：

1. **體力擊倒**：把對方體力磨到 0（下段攻擊會削弱耐力回復，利於消耗戰）。
2. **頭擊ＫＯ**：上段攻擊累積暈眩條，滿條即ＫＯ（即使體力尚存）。

否則三回合結束後比總分。

### 模式與流程

| 項目 | 本實作 |
|------|--------|
| 對戰 | 固定 1P vs CPU（無雙人同機） |
| 聯賽 | 六位對手階梯；打贏解鎖下一位（`league.ts`，`clubhouse-toy-boxing-league`） |
| 自由對戰 | 三角難度 × 四造型 |
| 回合 | 最多 3 回合，每回合 60 秒；回合間恢復約 30% 體力、部分暈眩 |
| 勝負 | 體力或暈眩ＫＯ立即結束；否則比累計分數；同分為和 |
| 角色 | 藍拳機器人／紅絨熊仔／閃電兔／鐵拳恐龍（各有招牌拳名） |
| 戰績 | 分難度勝／負／和與連勝（`stats.ts`）＋聯賽進度 |

### 戰鬥深度（`combat.ts`）

| 機制 | 說明 |
|------|------|
| 上／下段 | 攻擊與格擋皆分高／低；擋對減傷 80%，擋錯只減 20% |
| 預備動作 | 刺拳／勾拳／招牌拳有 wind-up → active → recovery；畫面拳套後拉可讀 |
| 撥招 | 僅對正確段位有效；成功使對方硬直並回饋必殺量 |
| 耐力 | 出拳消耗；下段命中提高對方 `bodyFatigue`，降低耐力回復 |
| 暈眩 | 上段命中堆暈眩；滿條頭擊ＫＯ |
| 招牌拳 | 長預備、無法格擋、可閃避 |

## 規則說明（本館）

### 準備／設定

1. 選自己的玩具；聯賽選已解鎖對手，或自由對戰選造型與難度。
2. 首次進入顯示首局引導；按「知道了」後寫入本機。
3. 開戰後倒數進入第 1 回合。

### 回合流程

1. **段位**：按住 ↓／Ｃ 為下段；放開為上段。
2. **出拳**：靠近後Ｊ／Ｋ；注意對方預備動作再決定擋／閃／撥。
3. **防禦**：Ｓ 格擋（依當前段）、Ｗ 閃避、Ｉ 撥招（須對段）。
4. **招牌拳**：紫色能量滿後Ｌ；對方只能閃避。
5. **回合結束**：時間到進入「下一回合」；第 3 回合結束或ＫＯ則結算。

## 勝負條件

- **體力ＫＯ**：對方體力歸零 → 勝。
- **頭擊ＫＯ**：對方暈眩條滿 → 勝。
- **判定**：三回合後 **總分高** 者勝。
- **平手**：總分相同 → 和局（計入戰績 draws）。
