# 海灣帆航（Sailing）

## 類別

運動機檯類型

## 概述

海灣帆航是一款 **3D 帆船繞標** 休閒競技遊戲。玩家駕駛單桅快艇，在開闊海面上依 **相對風** 調帆與操舵，完成多條風況不同的航線。畫面以 WebGL2 即時渲染海洋（Gerstner 波浪）、天空、帆船與浮標。

帆的推力依真實帆船簡化模型計算：在頂風區（約 32° 內）無法前進，橫風最快，側向力會造成傾側與偏航。風向會緩慢偏移、階躍轉向並夾帶陣風，使搶風換舷與航線選擇具有意義。

## 人數與建議年齡

- 人數：1 人（可與 CPU 對手同場）
- 建議年齡：10 歲以上（需理解風向與調帆概念）

## 所需器材

- **介面**：橫向畫面為佳；支援鍵盤與觸控。
- **操作**：
  - 鍵盤：`←` `→`（或 `A` `D`）轉舵；`↑` / `W` 加速（簡單模式）；`Q` / `E` 或 `Z` / `X` 收帆／放帆；`空白` 換舷；拖曳畫面環顧；`R` 重開。
  - 觸控：左下轉舵、右下「加速／一鍵換舷／調帆」。
  - 首次開航有「出航小抄」教學面板（可關閉，存於 localStorage）。
- **計分**：完賽時間；各航線／模式最佳成績、解鎖進度與海灣盃戰績存於本機。

## 遊戲目標

以最短時間完成選定航線；對戰與海灣盃則追求名次與積分。

## 規則說明

### 準備／設定

1. 標題選單選擇 **計時賽／對戰／海灣盃** 與航線。
2. 預設開啟 **自動調帆** 與 **簡單模式**（可關閉）。
3. 各航線有獨立風況：偏移幅度、陣風、階躍轉向不同。

### 航線

| 航線 | 重點 |
|------|------|
| 海灣環線 | 順風起航，閘門熱身 |
| 迎風折返 | 搶風上頂標、**左舷繞標**，再順風回航（完賽海灣環線後解鎖） |
| 繞島三角 | 三角繞標＋強陣風（完賽迎風折返後解鎖） |

### 模式

- **計時賽**：與個人最佳幽靈船競速；刷新最佳時覆寫幽靈。
- **對戰**：與「微風」「烈風」兩位風格不同的 CPU 同場。
- **海灣盃**：連跑三航線，名次積分 5／3／1，累計戰績。

### 回合流程

1. **起航**：倒數後計時。
2. **搶風／繞標**：依相對風調整航向；頂風區需走 Z 字。
3. **通過目標**：閘門需正向穿越；繞標浮標需以指定舷側繞過。
4. **完賽**：顯示成績、名次（對戰／盃賽）與歷史最佳。

### 可行動作與限制

- 自動調帆開啟時，帆角追蹤理想攻角；關閉後需收／放帆，放太鬆會抖帆。
- 完美穿門／繞標：扣時並短暫加速。
- 開闊海域無邊界；掉隊可按 `R` 重開。

## 勝負條件

- **完賽**：通過全部目標。
- **紀錄**：刷新該航線該模式本機最佳時間。
- **結算 UI**：共用 `@clubhouse/shared/resultOverlayDom`。
