# Dust Riot / Borderland

第一人稱荒土波次防衛（靜態 HTML + Three.js ESM）。

## 目標深度 5

- 難度三檔（輕鬆／標準／高壓）＋波次通關
- **每日突變**（Asia/Taipei 日期種子）：禁用武器、主力兵種、一則突變規則；今日最佳／連續天數／複製分享
- **永久解鎖（meta）**：通關／里程碑賺廢鐵，解鎖起始裝備或小型被動；`dust-riot-v3`
- 開局武器三選一：衝鋒槍／步槍／散彈（射程與身分取捨）
- 兵種：掠奪者／衝鋒／迫擊／盾兵；每 4 波精英（突變可改節奏）
- 桌面 Pointer Lock；手機雙搖桿＋開火／換彈／跳躍
- `prefers-reduced-motion`：減少鏡頭晃動／步伐顛簸／粒子
- 音效：`gpt6-astra/shared/sfx.mjs`

For anything that needs bitmaps/textures/sprites (or if it helps to have a mockup reference for any 3d models you build) feel free to use imagegen.
