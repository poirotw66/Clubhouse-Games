        How WebMCP powers this factory
        1. The factory exposes structured simulation capabilities.
        2. The AI agent observes actual production metrics.
        3. The agent identifies bottlenecks from resource flow and diagnostics.
        4. The agent decides how to improve capacity and spend credits.
        5. It invokes build, upgrade, recipe or conveyor tools.
        6. FactoryEngine validates and updates the shared simulation.
        7. Production changes in real time.
        8. The agent measures results and adapts.

        WebMCP does not automate mouse interaction. It exposes meaningful operations on machines, recipes, connections, resources, capacity and throughput. The AI still provides observation, diagnosis, planning and optimization decisions.

        The initial factory is genuinely simulated for three minutes before display, establishing a roughly 4 gears/min baseline. Rates are measured over a fixed 60-second window. Mission completion requires that rolling rate and recent production remain at target for 10 simulation seconds. Stored layouts restart their measurement window.

        Belts use adjacent-cell routes, have finite transport capacity and travel time, and cannot cross. Splitters fairly alternate eligible outgoing belts. Storage holds and forwards any resource. Upgrade multipliers are 1× / 1.5× / 2× for machines and 1× / 2× / 3× for conveyors.
