# 無盡火車（Endless Train）

> Astra／GPT-6 實驗。靜態實作：`gpt6-astra/train/`（`index.html` + `rules.mjs`）。

## 簡介

永不停止的火車：採集、鋪軌、趕在出軌／過熱前前進。深度 5：難度變體、今日種子＋每日修飾、災害格／特殊車廂、音效回饋、單人自動司爐與觸控 P1/P2 切換。

## 遊玩

- 總覽「07 Astra」或開啟 [`gpt6-astra/train/index.html`](../gpt6-astra/train/index.html)。
- **單人／雙人**（雙人共用鍵盤）；觸控可用虛擬搖桿＋右側按鈕，並以右上 **P1/P2** 切換操作對象。
- 單人可勾選 **自動司爐**：水低時 AI 會去河岸取水並送回車廂（人手搖桿優先）。

## 難度／規則變體

| 模式 | 體感 | 主要差異 |
|------|------|----------|
| 輕鬆 | 熟悉流程 | 火車較慢、水耗較低、開局鐵軌多、架橋 1 木材 |
| 標準 | 原本節奏 | 基準數值（與初版 demo 對齊） |
| 高壓 | 催得兇 | 更快加速、水耗更高、資源更稀、架橋 3 木材、開局水 85% |

另可選 **今日路線**：以當日日期產生固定種子（同日同地圖），並記今日最佳。

### 每日修飾（由種子解出 1～2 個）

| 修飾 | 效果 |
|------|------|
| 雙倍耗水 | 冷卻水消耗 ×2 |
| 便宜的橋 | 架橋木材 −1（至少 1） |
| 濃霧 | 視野變窄 |
| 暴風前線 | 暴風區更密、移動變慢 |
| 貨廂補給 | 開局多一次貨廂投放 |

### 災害與特殊車廂

- **斷橋**：河岸旁裂縫格，鋪軌需額外木材修復。
- **暴風區**：進入後移動變慢、水耗上升（畫面有風線）。
- **貨廂投放**（一次／可因修飾加次）：把倉庫物資丟到軌道前方（按 `C` 或觸控「貨廂」）。

車廂升級上限 **Lv.6**（升 5 次）。

## 結算／重玩

- 結束畫面：距離、區域、時間、新鋪鐵軌、結束原因、種子、模式／修飾徽章；本模式新紀錄／今日最佳提示。
- 動作：**再來一趟**（同模式隨機）、**今日路線**、**換模式**。
- `localStorage` 鍵 `unstoppable-train-v2`（依模式最佳；遷移舊鍵 `unstoppable-best` → 標準）。

## 觸控

- 粗指標／觸控：左側虛擬搖桿移動，右側「互動／鋪軌／丟下／升級」（≥44px）。
- 右上：P1/P2 切換、貨廂投放。
- 鍵盤：P1 `WASD`＋`E`/`Q`/`R`/`U`/`C`；P2 方向鍵＋`Enter`/`/`/`.`；`Tab` 切換觸控對象；`P`／`Esc` 暫停。

## WebMCP

瀏覽器支援 `document.modelContext` 時註冊：

| 工具 | 說明 |
|------|------|
| `train_get_state` | 讀取局況 |
| `train_start` | 開新局 |
| `train_get_modifiers` | 由種子解修飾 |
| `train_deploy_cargo` | 投放貨廂 |
| `train_set_touch_player` | 切換觸控對象 |
| `train_set_autofireman` | 開關自動司爐 |

不支援時人類 UI 仍完整可用。

## 技術備註

- 類型：`game`；純靜態 ESM（無 Vite workspace）；Pages 整包複製 `gpt6-astra/`。
- 規則純模組：`rules.mjs`（難度表、速度／水耗／製作時間、每日種子／修飾、災害判定、成績遷移）。
- 完整創作提示詞見同資料夾 `prompt.md`。
