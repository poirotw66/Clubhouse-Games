# 動力雕塑展（Exhibition Web）

## 簡介

當代動力雕塑展網站，含捲動驅動的機械節奏互動。

## 遊玩

- 從總覽選單「07 Astra」進入，或開啟 [`gpt6-astra/exhibition-web/index.html`](../gpt6-astra/exhibition-web/index.html)。
- 本目錄為實驗／展示規格摘要，完整提示詞見同資料夾 `prompt.md`（若有）。

## 技術備註

- 類型：`landing`
- 建置：純靜態 HTML（無 Vite workspace）；Pages 部署時整包複製 `gpt6-astra/`。
- **Fonts**：本機 `gpt6-astra/vendor/fonts/exhibition.css`（DM Sans + Manrope variable latin）；無 Google Fonts CDN。
