# 弓箭手（Archer）／停步射手（Stillshot）

> Astra／GPT-6 作品。靜態實作：`gpt6-astra/archer/`（`index.html` + `rules.mjs` + 共用 `shared/sfx.mjs`）。

## 簡介

移動時不能攻擊、停步才自動射擊的 Roguelite 房間戰。深度 5：音效、有意義永久樹、今日種子挑戰、分區 Boss 行為。

## 遊玩

- 總覽「07 Astra」或開啟 [`gpt6-astra/archer/index.html`](../gpt6-astra/archer/index.html)。
- 手機：拖曳移動，放開即停步射擊；電腦：WASD／方向鍵，`Esc` 暫停。
- 大廳可開關音效（設定寫入 `localStorage`，鍵 `astra-sfx-muted`）。

|------|------|----------|
| 輕鬆 | 熟悉節奏 | 敵血／傷害／數量較低，通關獎勵 120 |

| 玻璃突襲 | 限房變體（解鎖） | 雙方玻璃血，輸出為王 |

## 永久樹（取代純 +%）

金幣一次解鎖身分／結構，而非疊百分比：

- 開局能力：穿透／多重／護盾／冰霜
- 泉水客房：第 6、11 房改為治療房（無敵人）
- 突襲變體：夜襲、玻璃

舊存檔的永久攻擊／生命等級會折現為金幣（`stillshot-save-v3`，遷移 v2／legacy）。

## 戰術鎖敵與專注超載系統（Tactical Telemetry & Focus Overdrive）

- **戰術鎖敵準星（Target Lock Reticle）與預測導引光束**：
  - 移動時繪製預測導引虛線，停步前即清楚得知箭矢即將鎖定哪名敵人。
  - 鎖定目標以動態角規 `[   ]` 標記，並即時顯示敵人血量百分比、與英雄距離及蓄力危險警示。
- **專注蓄力超載（Stillness Focus Overdrive）**：
  - 將「停步射擊」的高風險站定行為轉化為感官成就：
    - 0.0s～0.6s：基礎瞄準法陣與鎖定粒子。
    - 0.6s～1.2s：符文聚氣階段（綠意法陣加速旋轉，環境光能粒子向英雄聚攏）。
    - 1.2s+：**專注超載（FOCUS MAX!）**，英雄腳下迸發金陽神聖法陣、雙向旋轉符文環與耀眼火花！
- **桌面端地下城戰術側翼儀表板（Cockpit Wings）**：
  - 寬螢幕（>= 990px）兩側展開戰術儀表，解決純直式畫面兩側空洞問題：
    - **左翼（戰術矩陣 · 裝備庫）**：專注超載蓄力條、即時作戰數值（攻擊力、射頻、暴擊、移速、減傷、閃避）、已習得能力列表（名稱、圖標、等級徽章）。
    - **右翼（探險雷達 · 戰況）**：15 房探險路線圖（標記一般房、精英房 ⚔️、泉水房 💧、守門者房 👑 與已通關狀態）、現場敵情偵測即時血量清單、音效開關與暫停快捷鍵。
    - 手機與窄螢幕無縫自適應隱藏側翼，純享極簡流暢觸控。
- **視覺震撼強化**：
  - 區域守門者降臨震撼警報橫幅（`WARNING · 區域守門者降臨`）。
  - 頂部守門者華麗血條框與二階段狂怒超頻特效。
  - 元素箭矢動態彗星尾跡與暴擊微震衝擊波。

## 結算／重玩

- 結束畫面：模式徽章、通關／陣亡／撤退、本模式／今日新紀錄。
- 動作：**再來一局**、**換模式**、**回營地 · 永久成長**。
- Agent 介面：`window.__ASTRA_ARCHER__`；若瀏覽器支援 `document.modelContext`，另註冊 `stillshot_*` WebMCP 工具。
