# 色感記憶（Dialed Color）

## 類別

迷你遊戲類型

## 概述

色感記憶（Dialed Color）是一款結合色感訓練、光學物理遙測與記憶挑戰的霓虹賽博駕駛艙遊戲：先短暫記憶目標色（或部分模式下的參考色／雙色），再透過 360° 環形極座標色度向量儀與精準光軌滑桿重現。

靈感來自 [dialed.gg](https://dialed.gg) 的色感測驗，並在全新版本中全面重構為「色相光譜戰情駕駛艙（Synthwave Chroma Cockpit）」，整合光譜調色雷達、光學波長估算、每日色彩星圖、共振錦囊，以及全新的 GF(2) 光矩陣點燈解鎖模式。

來源專案：[poirotw66/Dialed-Color-Game](https://github.com/poirotw66/Dialed-Color-Game)

## 人數與建議年齡

- 人數：1 人。
- 建議年齡：約 8 歲以上。

## 所需器材

- 觸控或滑鼠操作的 360° 環形色輪與色相／飽和度／明度滑桿。
- 鍵盤矩陣控制支援（WASD、方向鍵、空白鍵、Enter、H、R、1–6 快捷鍵）。
- 顯示目標色、猜測色與光學向量雷達的畫面。

## 遊戲目標

在短時間記憶顏色後，盡可能精準重現，取得高分；或以闖關／生存／閃擊／光矩陣等模式挑戰極限。每日挑戰讓所有人以同一組種子色一較高下，並可產出 Wordle 式分享文案。

## 規則說明

### 核心介面與戰情室架構

1. **左翼：光譜調色戰情雷達與光學分析儀**
   - **360° 極座標向量儀（Vector Scope）**：以極座標即時描繪調色向量（角度為色相、半徑為飽和度、核心為明度），支援直接點擊拖曳雷達調色。
   - **光學物理遙測串流**：即時換算可見光譜波長（λ，約 380nm–700nm）、相關色溫（TC，約 1800K–12000K）、十六進位 HEX 色碼與 RGB 光學數值。
   - **色感階位徽章**：依據玩家得分與連勝紀錄動態評定階位（光譜至尊、稜鏡指揮官、波長調諧師、光學航行者、色感研發員、光譜初生體）。
2. **中央：超導核心調色艙**
   - **360° 全光譜環形色輪**：平滑 Conic 色相漸層環，指針跟隨滑動；內圈核心呈現猜測色與光波脈衝。
   - **快速光譜靶點**：紅（0°）、黃（60°）、綠（120°）、青（180°）、藍（240°）、紫（300°）六大快速錨點，一鍵跳轉基準色相。
   - **精準微調光軌滑桿**：色相、飽和度、明度三軸光軌，搭配 ±1 與 ±10 步進按鈕。
   - **鍵盤戰術控制矩陣**：
     - `A` / `D` 或 `←` / `→`：微調滑桿數值（按住 Shift 以 ±10 大步進調整）。
     - `W` / `S` 或 `↑` / `↓`：在色相、飽和度、明度滑桿間切換焦點。
     - `Space` / `Enter`：確認提交猜測或於結算時繼續。
     - `H` / `P`：長按透視目標色。
     - `1` ～ `6`：快速校準至紅、黃、綠、青、藍、紫六大色區。
     - `R`：重置對局或重新整理。
3. **右翼：色彩星圖與共振錦囊**
   - **每日色彩星盤軌道**：將每日挑戰的 5 組色票或近期對局映射為極座標天體星座圖，各星宿節點標註色相與得分。
   - **光波共振錦囊**：即時計算當前顏色的互補色（+180°）、類似色（+30°）、三等分色（+120°）、分裂互補色（+150°），點擊可快速套用色相。
   - **戰術快捷手冊**：即時常駐顯示操作指引。
4. **行動端戰術速報條**
   - 螢幕寬度較小（< 1024px）時，頂部提供「調色艙」、「雷達」、「星圖」、「光矩陣」快捷切換標籤與微型色相狀態晶片，保持操作順暢不擁擠。

### 模式

1. **光矩陣點燈解鎖（GF(2) 模式）**：
   - 創新矩陣謎題模式，提供 3×3 與 4×4 兩種霓虹光點網格。
   - 點擊光點可反轉自身與上下左右十字鄰居的光源。
   - 內建 **GF(2) 有限體高斯消去線性代數求解器**：
     - 即時預測全熄滅所需的「最小求解步數」。
     - 提供「求解提示」，高亮顯示下一步最佳反轉光點。
     - 「對稱性圖騰分析」：解析水平、垂直、對角線對稱性（例如：全域超弦共鳴圖騰、雙軸鏡像聖十字、水平光鏡圖騰等）。
     - 熄滅矩陣所有光源即解鎖破譯光譜成功！
2. **每日挑戰**：以 **Asia/Taipei** 日曆日期為種子，當天所有人同一組 5 色。完成後可複製分享結果（🟩🟨🟧⬛ 色格 + 平均分 + 連勝）。連勝依連續完成的台北日計算。
3. **單色挑戰**：記憶 1 色，以色感滑桿重現（可調記憶秒數 3／2／1 秒）。
4. **五色連續**：先連續顯示 5 色，再依序重現；取平均分。
5. **闖關模式**：共 5 關，顯示時間逐關縮短（約 2.0 → 1.5 → 1.1 → 0.8 → 0.55 秒）。單關須達 **650** 分才進入下一關。
6. **混色調配**：短暫顯示兩色，調出其（光色）混色結果。
7. **互補色**：顯示參考色，調出色相 +180° 的互補色。
8. **類似色**：顯示參考色，調出色相 ±30° 的類似色（題目會標明方向）。
9. **限時閃擊**：60 秒內盡量完成多回合（短顯示），累計總分。
10. **無盡生存**：關卡漸難（顯示更短、色相更近、過關門檻升高），直到未達門檻為止；紀錄最高關數。

### 操作與計分

1. 顯示結束後，以 360° 環形色輪、極座標雷達或滑桿調出猜測色。
2. 提交後進入**回合回饋**：並排比較猜測／目標，並以色相／飽和／明度差值長條解釋距離。優秀匹配（≥850）有粒子特效與音效。
3. 非閃擊模式可按住「提示」或按 `H` 鍵短暫透視目標色（練習用）。
4. 計分依猜測色與目標色在 HSL 空間的距離：完全一致為 999 分。
5. 最佳單分／平均（依秒數）、各模式最佳、生存關數、閃擊總分、統計與近期對局、每日連勝寫入瀏覽器 `localStorage`。

### 無障礙／色盲友善

- 可開啟「色盲友善」：色票加上依色相區段區分的圖樣（斜紋、點陣、橫線、格紋、菱形、波紋），並顯示 H 數值標籤，減少只靠色相辨識。

## 勝負條件

- 單色／五色／每日／混色／互補／類似：以平均分數（0–999）衡量表現。
- 闖關：通關 5 關為成功；任一關低於 650 分為失敗。
- 生存：未達當關門檻即結束；追求更高關數。
- 閃擊：時間到結算總分。
- 光矩陣點燈：以最少步數熄滅所有光源為勝利。
- 可重複挑戰；每日挑戰種子全日固定。
